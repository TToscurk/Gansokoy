# 《緣一・幻想鄉》地圖品質升級書
> 主題：把地圖從「過場關卡」升級成「真實存在的地方」。
> 基於 main（81aac4e）程式碼分析。依感受影響排序。一次做一項，
> 有視覺取捨的項目一律截圖 A/B 給我決定。與 /buildloop 蓋新圖分開跑。

---

## 升級 1：遠景延伸系統（解決「邊界都是高邊坡擋起來」）

**現況**：圖邊界靠高邊坡＋controller 的座標夾制（空氣牆本身沒問題，
_clampToBounds 的做法是對的），但視覺上邊界＝一道土牆，玩家知道
「世界到這裡就沒了」，過場感的最大來源。

**目標**：站在獸道就能隱約看到人間之里的屋頂輪廓、看到神社方向
山上的鳥居剪影——每張圖的邊界之外，鋪出鄰接地圖的低模剪影遠景，
罩在霧色裡。空氣牆照舊存在，但玩家看出去是「路通向遠方的下一個地方」，
不是牆。

**做法**：
1. 新增 src/world/vista.js：讀 mapRegistry 的 connections，
   對每個連接方向，在圖界外 60–150m 處擺放該鄰圖的「剪影組件」——
   超低模（每組 < 500 三角形）、單色或雙色、不投影不受光
   （直接吃霧色調），例如：
   - village 的剪影組件＝一排屋頂輪廓＋里門
   - shrine＝山坡上一座鳥居＋石階折線
   - bamboo＝一整片漸淡的竹稈剪影
   - lake＝低平的水面反光帶＋薄霧
2. 剪影只做「一眼認得出是什麼」的程度，細節靠霧遮。fog far
   調到剛好讓剪影落在半霧裡（每張圖已有獨立 fog，順手校）。
3. 傳送點升級：makePortalGlow 的光點後方，加一面帶模糊感的
   「門後景深」——低模剪影＋一層半透明霧牆 shader（顏色取
   目的地圖的 fog 色），走近時剪影微微視差移動。效果＝
   「透過這道門隱約看得到那邊的世界」。
4. 邊坡不是全拆：邊坡在「劇情上合理」的地方保留（獸道是山谷，
   兩側是谷壁天經地義），但谷壁上緣之外要有東西——遠山稜線、
   更高處的樹冠剪影，不能是天空直接切斷。

**驗收**：獸道往人里方向走，未到傳送點前就看得到里的屋頂剪影；
每張圖站在中央環顧一圈，沒有任何一個方向是「土牆頂著天空」。

## 升級 2：碰撞升級——可以站上去，而不是被彈開

**現況**：controller 的 _resolveCollisions 已有 c.walk 旗標
（站上頂面時不做水平阻擋），但多數建築/裝置的碰撞體沒開這個旗標，
所以跳上去的瞬間被圓柱/方盒推出——就是你說的「強制位移到旁邊」。

**做法**：
1. 盤點全部碰撞體：矮於 4m 的（橋、圍牆、石燈籠、攤位、木箱、
   矮屋簷）一律補 walk: true ＋正確的頂面高度——跳上去就站著。
2. 人間之里的石橋：確認橋面是可走的（heightAt 有河床，橋要嘛
   自己是 walk 平台、要嘛在 heightAt 對橋的 x/z 範圍回傳橋面高度）。
   現在「橋不能經過」就是這裡斷了，優先修。
3. 高建築（民宅、拜殿）屋頂：跳不上去的維持阻擋，但推出方向
   必須是水平法線、絕不往上疊加——落在牆頂邊緣時沿牆面滑下來，
   不是瞬移。
4. 順手加著地判定的寬容：站在 walk 平台邊緣 0.3m 內不要抖動滑落。

**驗收**：跳上人里的每一座橋、攤位、圍牆試一輪，沒有任何一處
出現瞬間位移；橋能正常過河。

## 升級 3：路人 AI 升級（不卡建築、有日程、像在生活）

**現況**：villagers.js 是節點圖隨機走（_nextFrom 避免走回頭路），
但節點之間直線移動，路徑上有障礙就會頂著建築磨蹭。

**做法**：
1. **避障**：移動時往前方 2m 探測（對 colliders 做圓查詢，
   不用 raycast，controller 已有圓柱/方盒資料可共用），
   前方受阻→沿障礙切線方向偏轉；連續 2 秒位移 < 0.3m 判定卡死
   →放棄目前目標、回到最近的路網節點重新選路。
2. **日程 AI**（你說的 mission AI 我理解為這個，如果是任務護送
   類另外跟我說）：路人給時段行為表——
   - 清晨：往市集節點聚集（攤販定點、買菜的遊走）
   - 白天：街上正常遊走
   - 黃昏：往燈籠節點（點燈動作可以只是站定＋燈籠此時亮起）
   - 夜晚：大半消失（回家），留少數提燈夜行者
   daycycle.js 已有遊戲內時間，直接掛上去。人數增減用現有的
   路人池慢慢淡入淡出，不要整批瞬間消失。
3. NPC（有名字的）不用日程，但同樣吃避障。

**驗收**：人間之里開 10 分鐘觀察：沒有任何路人頂著牆原地踏步；
切換清晨/黃昏，街上人流分布肉眼可見地不同。

## 升級 4：河道加寬＋橋重做

**現況**：河半寬 9m（rd < 9）、深 1.6m——比較像水溝。

**做法**：河半寬加到 16–20m，河床加深到 2.5m，蜿蜒幅度加大；
橋隨之加長、微拱加高，橋下淨空讓視線穿得過去；河裡加淺灘石、
蘆葦叢（InstancedMesh）；水面 shader 流向順河道中心線。
東岸（河對面）鋪一條窄堤道＋兩三戶人家，讓「過橋」有目的地，
不是過去就是圖邊。

**驗收**：站在橋上截圖——河要「像一條河」。

## 升級 5：地圖 UI 與導航系統（解決「找不到香霖堂」）

**現況**：完全沒有地圖 UI。香霖堂本身還沒蓋（built: false），
但就算蓋好了，現在玩家也只能靠亂走找傳送點。

**做法**：
1. **大地圖（M 鍵）**：讀 mapRegistry 畫節點連線圖——每張圖一個
   節點（用 REGIONS 的 x/z 相對位置擺），connections 畫成線，
   built: false 的節點顯示成「？」剪影（可以看到方向但標示未探索/
   尚未開放），目前所在圖高亮。手繪風格：紙底色＋墨線，
   不要科技感 UI。
2. **小地圖（常駐右上角，可關）**：目前這張圖的俯視簡圖——
   路網（pathnet 的中心線直接畫）、傳送點圖示＋目的地名、
   玩家箭頭。用 canvas 2D 畫一張靜態底圖＋動態玩家標記，
   不要每幀重繪整張。
3. **傳送點的世界內標示**：每個傳送點旁立一個小道標
   （木牌/石標，寫目的地名，走近才看得清），配合升級 1 的
   門後景深——遠看剪影、近看道標，兩層引導。
4. 任務有目標地點時，大地圖上該節點標記＋小地圖邊緣方向箭頭。
   不做世界內的懸浮路徑線——太出戲，與美術方向不合。

**驗收**：一個沒玩過的人能在 1 分鐘內靠 M 鍵知道
「香霖堂在人里的西邊、還沒開放」。

## 升級 6：迷途竹林重做——真正的迷宮

**現況**：竹林有明顯的路（PathNet 路面配色），照著走就出去了，
「迷途」名不副實。

**目標**：沒有可見道路。靠地標、暗示、記憶認路——迷路是這張圖
的玩法本身。

**做法**：
1. **拆掉路面視覺**：地面全圖統一材質（落葉腐植土色，微暗），
   PathNet 保留為內部資料（NPC/兔子移動、出入口判定還要用），
   但路面不再有顏色/材質差異。
2. **地標引導系統**（取代道路）：
   - 綁紅布條的竹子：從入口到永遠亭的「正解路徑」上，每隔
     30–40m 一根，但布條方向刻意只在接近時看得清
   - 石燈籠（稀疏、部分傾倒）：靠近永遠亭方向密度漸增，夜晚微亮
   - 地藏石像：岔路口擺，面朝的方向是暗示（面向正路）
   - 竹筍密集區：出現在死路端（「長太密走不過去」＝軟性死路）
   3. **方向感干擾**：進入竹林深處（離邊界 > 60m）後小地圖
   （升級 5 做的那個）改顯示「？」，只剩大地圖看得到自己在
   竹林這張圖但不顯示圖內位置——迷路要真的會迷路。
   妹紅嚮導保留：付費/對話直達永遠亭，是「安全出口」。
4. **可砍的竹子**：
   - 竹子加 HP（3 刀），InstancedMesh 每株一筆狀態
     （mobcore 的思路：渲染歸 instance，狀態歸陣列）
   - 斷竹動畫：命中第 3 刀→該 instance 從砍擊高度處分成上下兩段，
     上段繞斷點傾倒（0.8s 的旋轉＋落地輕彈），落地後 2s 淡出；
     下段留一截斷茬，5 分鐘後原地長回（縮放從 0 到 1 的冒出動畫）
   - 砍竹開路＝迷宮的另一種解法：死路的竹筍密集區其實砍得穿，
     捨得花時間就能開捷徑——迷宮因此「可被玩家改寫」
5. **竹子多樣化**：
   - 粗細：半徑 0.06–0.22m 隨機（決定性亂數，同一張圖每次進來一樣）
   - 高度：8–16m，粗的傾向高
   - 顏色：三種綠（嫩綠/正綠/黃綠帶枯斑）按 6:3:1 混
   - 傾斜：±4° 隨機傾角
   - **筍株**：一個基座冒出 3–6 根不等高的竹筍/幼竹（0.5–3m），
     佔比約總量 25%，聚落式分布（用 noise 決定聚落中心）——
     這是你要的「地上一串長出來」的那種
   - 老竹段：2% 的竹子做成攔腰折斷的枯竹，增加野地感

**驗收**：拿掉小地圖、第一次進竹林的人應該要迷路至少一次；
砍竹 3 刀斷、有倒下動畫；截圖裡找不到兩根一模一樣的竹子。

## 升級 7：全圖「正式感」通則（之後蓋新圖與回修舊圖都適用）

過場感的解藥拆成四件事，寫進蓋圖慣例：

1. **三層景深**：每張圖必須有 玩法層（可走）＋中景層（走不到但
   看得清：對岸人家、坡上的田）＋遠景層（升級 1 的剪影）。
   現在多數圖只有玩法層，這是「像關卡不像地方」的核心原因。
2. **環境生命**：每張圖至少兩種 idle 動態——炊煙、飛鳥剪影
   （3–5 隻的 InstancedMesh 繞圈）、落葉/花瓣粒子、水面漣漪、
   晾曬的布幔飄動。便宜但把「靜物佈景」變成「活著的地方」。
3. **視線設計**：每個傳送點/入口望進去的第一眼要有構圖焦點
   （里門框住街景、竹林入口的第一根紅布條竹）。蓋新圖時
   先擺焦點再鋪裝飾。
4. **不對稱與不完美**：圍牆缺一段、其中一盞燈籠是歪的、
   有一戶屋頂在補瓦——完美整齊＝佈景感，破綻＝生活感。
   每張圖至少三處刻意的不完美。

## 執行順序建議

影響最大：**1（遠景）→ 5（地圖UI）→ 2（碰撞）→ 3（路人AI）**
→ 6（竹林重做，工程最大）→ 4（河道）→ 7（通則，寫進慣例即可）。

升級 6 的可砍竹子如果做起來卡（InstancedMesh 逐株狀態＋動畫
有技術細節），可以先出「多樣化＋無路迷宮＋地標引導」，
砍竹當第二階段——迷宮體驗不依賴砍竹。
