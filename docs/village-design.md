# 人間之里 v2 設計書（審查定案版）

v1 被退回的理由（自我驗收也過不了）：房子散在空地、棟距太大、沒有巷弄與
圍籬把街縫起來 → 讀起來是郊區不是聚落；460m 只有 39 棟；沒有生活痕跡；
房型單一；村界虛無。

## 定案（/grill-me 審查）

| 題目 | 你的答案 |
|---|---|
| 街廓型態 | 多排橫排與直排的商街與民宅、**1.2 條主街**、銜接東方 NPC 住宅與地標、**有密度感、視線有終點、日式時代劇** |
| 河川 | **這輪就做**，並驗收地圖 BUG |
| 火見櫓 | **要**（全村最高點，村外可見的垂直地標） |
| 規模密度 | **小而密**（城區收縮、棟距壓緊） |

## 空間結構

```
                    北門（→獸道 0,-174）
                        ‖  本通（主街・南北貫穿）
    ┌───────────────────‖───────────────┐
    │ 町家連棟 │ 町家連棟 ‖ 町家連棟 │ 稗田邸│   ← 商店街（北段）
    │──小巷──│──小巷──‖──小巷──│      │
    │        寺子屋      ‖   鈴奈庵    │  ⇢ 石橋 ⇢ 河（東）
    ├────────────────────╫────────────────┤  ← 橫町（0.2 條主街・東西向短街）
    │  廣場：水井・高札場・火見櫓・市集   ‖ │
    │──小巷──│──小巷──‖──小巷──│      │
    │  農家   │  農家   ‖  農家   │ 柴堆 │   ← 住宅（南段）
    └───────────────────‖───────────────┘
        西南門（→香霖堂 -132,100）  柵欄＋田環帶
```

- **本通**：南北主街，寬 6m，從北門直達南端；兩側連棟町屋（山牆貼山牆）。
  視線終點 = 廣場的**火見櫓**（12m 木塔，全村最高）。
- **橫町**（0.2 條）：東西向短街，只橫跨城區中段，東端接**石橋過河**。
- **小巷**：連棟町屋之間每隔幾棟開一條 2.5m 巷，通到後排民宅。
- **街廓（block）**：橫排×直排的方格，每格內有房屋 + 後院（柴堆、水缸、菜畦）。

| 類型 | 用途 | 特徵 |

| 稗田邸 | 稗田家宅邸 | 圍牆＋門長屋、最大的宅子 |

NPC 系統上線後，這些地標直接當住址用（慧音→寺子屋、小鈴→鈴奈庵、阿求→稗田邸）。

## 生活痕跡（讀起來像有人住）

水井、高札場（告示牌）、市集攤群、柴堆、水缸、稻架、竹竿曬衣、
石燈籠、村界木柵欄、田埂與稻苗。

## 河川（全世界第一段）

- 位置：城區東側，南北向蜿蜒；橫町東端一座**石橋**跨過。
- 做法：`gen_lib.river()` —— 河道折線 → 下切河床（U 形斷面）+ 河灘遮罩
  + 水面 mesh + `water.gdshader`（雙層法線捲動、深淺色、邊緣泡沫）。
- 北端往圖外延伸（`mapRegistry` 的 village↔lake 河畔道接口）。
- 河道工具進 gen_lib，其他圖沿用（霧之湖、玄武之澤都要）。

## 遠景

西北＝妖怪之山主峰、東北＝神社東山、南＝竹海色帶（色帶系統首度落地）、
西南＝香霖堂方向的林緣暗帶。

## 驗收清單（這輪一起做）

- [ ] 走一趟北門→廣場→南端，沒有穿模、沒有懸空、沒有卡住
- [ ] 河：走不進去（有碰撞）、橋能過、水面不閃爍
- [ ] 房屋不重疊、不壓在街上、不壓在河上
- [ ] 火見櫓從村外看得到
- [ ] 傳送點兩個都能用（北門獸道、西南門香霖堂）
