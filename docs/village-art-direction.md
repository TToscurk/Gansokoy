## 1. 風格基準線（2026-08-05 第二次 grilling 改版）

**目標一句話：類超現實的風格城市。** 拆解成可執行的四條：

| 項目 | 決定 |
|---|---|
| **「類超現實」的內容** | **(c) 夢境氛圍**：光柱、飄浮粒子（花瓣／螢火）、薄霧 + **(d) 誇張比例**：建築更高、街谷更深、透視更戲劇化。（**不是**新海誠式全面超飽和，也不加幻想物件——那兩項使用者沒選） |
| **天空** | **最高優先的單項工程。** 參考圖裡天佔畫面一半（鈷藍 + 大積雲），我們現在是一片淡漸層 |
| **描邊** | **定案：不做。** 參考圖沒有描邊 |
| **各圖標準** | **可以不一。** 人里走高調明亮；迷途竹林（以後）可以走參考圖 1 的暗調寫實粗竹 |

### 1.1 關鍵診斷：兩張參考圖是同一款遊戲

使用者對《幻走》竹林圖「無感」、對街道圖「很好」——但兩張是**同一套
資產管線**。差別在光與色：街道圖是高調性光、鈷藍天積雲、白牆發光、
紅燈籠色點、近乎無髒污。**「超現實感」主要是光照與色彩管理造出來的。**

因此工序上：**先做便宜的光色驗證**（天空＋後處理＋材質去髒，模型不動，
同機位對比圖給使用者判斷），確認方向再動貴的資產管線。

### 1.2 管線規矩（Q4 定案）

**所有模組——含建築——逐步搬進 Blender。** 產生器只管排版拼裝。
順序：**從難度最高的開始**（地標建築 → 町家套件 → 圍牆／小物）。
既有規矩不變：Blender 先做、`preview.py` 看過才進場景。

### 1.3 材質（Q5 定案）

十二組程序化貼圖**保留**，去髒污、提飽和、減弱法線強度。不重烤成手繪風。

### 1.4 驗收方式

每輪拍**同機位改前／改後對比圖**，使用者看圖判斷。不用抽象的驗收句。

### 1.5 光色方向已定案（2026-08-05）

第一輪光色驗證（積雲天空 + 高調性後處理 + 材質去髒，模型不動）
使用者判定：**「b方案很好」**。此後所有畫面工作以這個光為基準，
不要回頭調暗、調灰。

### 1.6 提灯串的教訓

橫跨街道的提灯串試過又拆了（使用者：「把這個慶典燈籠竿子拿掉」）——
光禿撐桿 + 橫繩 + 浮著的橘方塊，遠看像電線桿掛施工燈。
祭典色彩由幟旗／暖簾／幔幕承擔；提灯要回來只能**貼著建築**掛
（屋簷下、店門口），不要橫跨街道。

## 2. 硬指標

| 項目 | 決定 |
|---|---|
| **效能取捨** | 畫面優先，但**效能三件套排在所有畫面工作之前** |
| **目標硬體** | 現在：Intel Xe 筆電／之後：**GTX 1070** |
| **色彩濃度** | **祭典等級** —— 燈籠串、旗幟、幔幕 |
| **朱紅（博麗色）** | 可以稍微加入 |
| **庭池** | **池泉庭園**（有水、曲岸、中島、石橋），不是枯山水 |
| **稻田** | **留著，但要重做**。⚠ v19 試過撒畦與水鏡失敗（田面起伏 >0.2m，水鏡變成 704 塊玻璃板，使用者要求拿掉）——正確做法要先把田整成**梯田式平整台地**（地形工程），才輪得到鋪水 |
| **幾何合併器** | 先不做 |
| **「做完」的定義** | **可玩的場景**：有 NPC、商店、可進的室內 |

### 2.1 效能三件套

⚠ **每一項加畫面的工作之前，這三項要先做完。** 不然只會愈加愈卡。

不動幾何、只改屬性：

1. **`visibility_range_end` 距離剔除**
   小裝飾件（柱／貫／窗框／格子／雜物／樽／俵）在 40~80m 外不畫。
   全村橫跨 500m，任一時刻畫面裡只有一小塊 —— 預估砍掉
   **60~70% 的有效 draw call**，而且玩家看不出來。
2. **小件關陰影**（`cast_shadow = OFF`）
   陰影 pass 等於把所有東西再畫一次。小於 1m 的裝飾件關掉等於再省一半。
3. **縮短 `directional_shadow_max_distance`**

**驗收要目視確認遠處沒有東西突兀地「消失」**——距離剔除最容易出這個問題。

### 2.2 draw call 基準

```bash
grep -c 'type="MeshInstance3D"' godot/maps/village/village.tscn
```

**基準：11,825**（v18）。正常的遊戲場景該在 2,000 以內。

⚠ 距離剔除**不會**讓這個數字下降 —— 它減少的是「同時被畫出來的數量」。
要靠實機目視與 Godot 的 Rendering monitor 判斷。

## 3. 尺度規則

### 3.1 內外一致（硬規則）

使用者原話：

> 「我站在建築物前面就能感受到裡面的大小與這個房子內部是一致的感覺」

因為「做完」的定義包含**可進室內**，這條從美感問題變成**可驗證的硬規則**：

- 室內以**京間 1.82m** 為模數排榻榻米與柱距
- 建築外部 footprint 必須裝得下室內配置（外 ≥ 內 + 牆厚）
- **要變成 `check_map.gd` 的一條自動檢查**：有室內的建築，
  外部 footprint 面積 ≥ 室內面積 × 1.15，否則報錯

### 3.2 地標尺度

| 建築 | 現在 | 目標 |
|---|---|---|
| **稗田邸** | 村內街區的程序化二層入母屋（v19） | **⚠ 使用者新計畫：整棟重做成「村外的豪宅大院」**——不放在村內街區，自己一片地。做法 = Blender 模組（難度最高優先的那一件，§1.2）。村內原街區之後改回一般院落 |
| 寺子屋 | 22 × 12 × 高 4.6（坐 1.5m 石垣） | 維持或再拉高一階 |
| 一般町家（町方） | 二層 5.4~6.6m | 維持 |

使用者明確點名的顧慮：

> 「要確保建築不會有算錯卡到其他東西的問題」

**放大會撞既有的地權系統。每次改尺度都要跑滿 `check_map.gd` + `walk_test.gd`。**

### 3.3 街道

維持現況：本通 8m／橫町 7m／巷道 4.5m。
**窄街才襯得出建築高**——放大地標後若比例失衡再回頭調，不要先動街寬。

## 材質變化的通則（2026-08-07，使用者裁決）

「同一個物件重複太多次看起來單一」的情況，優先做法是**同色系內的
材質參數化變化**——色相/明度隨機擾動、新舊分級、上漆/未上漆的等級
差——而**不是**引入跟整體美術語言脫節的全新材質類別。

實例（稗田邸三樓書見台基座）：整層是溫潤木質調，第一版基座用石砌，
一顆粗糙石感跳出來很突兀。改法不是換一種更好看的石頭，是回到木系：
上過漆的深色木（更深、更有光澤、roughness 0.22）對比架上未上漆的
原木（roughness 0.8）——「這是核心錨點、比周圍更講究」用**材質等級
的細微差異**說，不用材質類別的跳躍說。

既有的正面例子同一條線：卷軸紙的三色調（年代感）、疊的棋盤格兩色調、
MAT_TONES 每種建材四色調 —— 都是同系內分級。

## 幻想鄉優先於考證（2026-08-08，使用者裁決）

**人間之里不是歷史日本復原場景。**

歷史考據**服務於可信度**，但不支配幻想鄉。判準是「這裡住得下人嗎」，
不是「這在江戶時代存在嗎」。

允許並鼓勵自然共存的東西：

- **外界流入物** —— 從博麗神社／結界縫隙流進來的器物、包裝、材料
- **不同年代的文化層** —— 同一條街上出現不同時期的做法、修補、替換
- **妖怪技術** —— 非人做的東西，人類拿來用
- **超自然元素** —— 護符、結界、供物；它們是**設施**不是裝飾

### 這條規則怎麼用（避免變成藉口）

- 這**不是**「什麼都可以放」。判準仍然是「有人長期生活」——
  外界物要有人**在用**的痕跡，不是擺出來給玩家看的彩蛋。
- 混雜要有**比例**：一條街的主調仍然是這個聚落自己的做法，
  外來物是少數、是被吸收進日常的那幾件。
- 已通過審圖的 Phase 1〜2.6b 語彙（真壁造・桟瓦・材質方向・
  店先の設え）**仍然是基準**。這條規則放寬的是「題材」，不是品質。
