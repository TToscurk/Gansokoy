# 邊界風景設計書 —— 每張圖的地平線該看到什麼

> **⚠️ 狀態（2026-08-26）**：本文件的**地理設計（誰的地平線看到誰）仍有效**，
> 但實作對照多為 three.js 時代快照：「已建成八張」不是 Godot 現況（Godot 只有
> village／trail／kourindou／hieda 系列／slice）；方位座標源自凍結的
> `src/config.js`；遠景實作入口是 `gen_lib.gd` 的 `vista()`／`boundary()`
> （`_build_vista` 只存在於 `gen_kourindou.gd`）；`vista_mountain.glb` 不存在。
> 把本文當地理願景讀，不當現行清單讀。

遠景系統（gen_*.gd 的 `_build_vista`）的內容依據。原則：**站在圖裡往外看，
地平線上要出現「隔壁地圖的臉」**——玩家還沒去過就先看到，傳送過去時才有
「我走進了剛剛看到的那片風景」的連續感。

考據基礎：東方沒有官方地圖（[東方維基](https://zh.touhouwiki.net/index.php?title=%E5%B9%BB%E6%83%B3%E4%B9%A1&variant=zh-tw)），
方位共識來自《求聞史紀》與同人整理（[幻想鄉地理](https://guild.gamer.com.tw/wiki.php?n=%E5%B9%BB%E6%83%B3%E9%84%89%E5%9C%B0%E7%90%86&sn=559)、
[幻想鄉全景討論](https://forum.gamer.com.tw/G2.php?bsn=10039&sn=2815)）：
博麗神社在最東端結界上、妖怪之山在西北、霧之湖在山腳、
迷途竹林在山的對面（南）、太陽花田在山的反方向（東南）、
香霖堂在神社/人里/魔法之森之間。本專案 `src/config.js` 的 REGIONS
座標就是照這個共識排的，方位一律以它為準。

## 全域地標（多張圖共用的遠景元素）

| 地標 | 可見範圍 | 呈現 |
|---|---|---|
| **妖怪之山** | 幾乎全圖的西北方 | 最高的遠山剪影，山頂常駐雲；全世界的方位錨點 |
| **博麗神社的東山** | 中西部各圖的東方 | 較矮的丘陵帶，山腰隱約一點紅（鳥居/社殿） |
| **魔法之森** | 西南各圖 | 暗綠近黑的密林色帶，比一般林地暗兩階 |
| **迷途竹林** | 南方各圖 | 黃綠色的竹海，質感均勻（和闊葉林的顆粒感區分） |
| **太陽花田** | 東南各圖 | 一條亮黃色帶，非常好認 |

### 迷途竹林 bamboo（-60, 840）
四面都被竹海包住是這張圖的個性——遠景主體就是**竹海本身的波浪**，
只在縫隙裡透出地標：北＝人里方向的天色亮一點（可望不可即），
南＝永遠亭的和式屋頂群從竹海探出，西＝魔法之森/無緣塚的暗林，
東＝無名之丘的紫色山腹。

### 永遠亭 eientei（-50, 980，最南端）
北面竹海一路鋪回去（來時路），其餘三面是更深的竹海與極淡的遠山——
「與世隔絕」就是這張圖的題目，遠景刻意單調。

## 實作備忘

1. 遠景=三層：遠景地形（丘陵/山剪影）→ 遠景樹帶（大棵、無陰影）→
   色帶（花田/竹海用調色的地形帶呈現，不用真種花）。
2. 全域地標做成共用資產：`vista_mountain.glb`（妖怪之山）等，
   各圖依方位擺，世界觀才會一致。
3. 邊界一律空氣牆（`_build_boundary`），不再用地形坡牆擋人。
