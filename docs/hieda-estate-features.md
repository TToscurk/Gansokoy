# 稗田邸（村外豪邸）Feature List

**來源**：使用者 2026-08-05 提供的完整功能清單（原文濃縮）。
**狀態標記**：✅ 已做｜🔨 本輪動工｜⏳ 排隊中

| 項目 | 規格 | 狀態 |
|---|---|---|
| 誇張軒反り | 屋簷四角沿 Z 抬升 **1.0m**，神殿級飛翹曲線 | 🔨 |
| 屋頂陡峭化 | 配合軒反り拉陡 | 🔨 |
| 腰簷（錣葺き） | 牆中段 ~3.2m 處切一圈寬 1.0m 外突腰簷，給格子窗長條陰影 | ⏳ |
| 唐破風玄關 + 高地基 | 地基 0.8~1.0m、5 階木階梯、正門上方 S 曲線唐破風 | ⏳ |
| 一體化外壁木框架 | 白牆表面擠出 5cm 厚 × 15cm 寬深色木框與格子窗 | ⏳（打樣已有柱樑，未達擠出規格） |
