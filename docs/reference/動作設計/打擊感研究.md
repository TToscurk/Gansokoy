# 打擊感研究（製作動作時必讀）

- 來源：水蛭 JogsLeech〈我做了一個遊戲，告訴你遊戲打擊感是怎麼來的？〉
  https://www.youtube.com/watch?v=Nwa-zMRWDXM （2026-08-18，14:46，UE5 示範）
- 研究方式：影片無字幕 → Whisper 轉錄全片 ＋ 每 4 秒截圖逐段讀畫面（2026-10-19）。
  逐字稿：同資料夾 `打擊感_逐字稿_JogsLeech.txt`（Whisper 有同音錯字，例如「手機反饋」＝受擊反饋、「卡肉」＝hitstop）。
- 注意：此片是《影之刃零》＋盖世小雞業配，片中對該作的稱讚屬宣傳，不當設計依據；只採用可操作的技術原則。

---

## 1. 核心觀念

1. **遊戲知道你打中，不代表玩家知道。** 扣血是電腦裡的事，打擊感是把「命中」翻譯成玩家看得到、聽得到、感覺得到的回饋。
2. **追求可信，不追求真實。** 刀砍下去的真實聲音不重要，重要的是讓大腦相信「這刀很狠」。（與動作電影同理：考慮的是鏡頭裡好不好看，不是現實能不能打死人。）
3. **打擊感是疊出來的。** 每一層單獨看都很小，缺一層就怪。影片的順序就是由便宜到昂貴的檢查清單（下節）。
4. **特效的目的是資訊，不是華麗。** 玩家不看 UI，光看畫面炸出的粒子也要知道剛剛發生了什麼（攻擊類型以顏色區分等）。
5. **節奏高於一切單項。** 全程都快，一分鐘就麻了；真正的衝擊來自快慢對比與停頓的「呼吸感」。

## 2. 分層清單（影片示範順序）

| 層 | 內容 | 要點／數值 |
|---|---|---|
| 1 受擊反應 | 命中時敵人播受擊動作 | 「力產生了結果」。進階：依**方向／部位／輕重**播不同受擊動作；再疊**物理骨骼偏移**（沿攻擊方向微推骨骼，例：黑魂3 舞娘）。單一死板受擊動作＝任何招打中都一樣，只是起點 |
| 2 音效 | 揮擊聲＋命中聲 | 兩者**缺一不可**，單放一個就怪。每類準備**多組隨機挑選**，並對音高做**隨機偏移**消除重複感。再加：受擊慘叫、**依材質不同的命中聲**、**低頻衝擊**。大招／重擊／處決**另行設計** |
| 3 動作設計 | 攻擊動畫本身 | 動畫要讓玩家潛意識讀到：**出招前蓄力、重心移動、肩帶動手臂、是手腕揮還是全身揮、揮完有無收招**——這些告訴玩家武器有多重。**換武器不換動作＝打擊感不可能成立** |
| 4 鏡頭震動 | 命中瞬間鏡頭震一下 | 每段攻擊在命中點放震動通知；**沿揮刀弧度**搖、FOV 微變。示範值 shake scale 2.0。**不能貪**：太大玩家看不清，「攝影師該買穩定器了」 |
| 5 特效 | 刀光拖尾、命中閃光、血液粒子、刀痕貼花 | 示範另含擊退距離 50（UE 單位 cm ≈ 0.5 m）。設計時以**可讀資訊**為準 |
| 6 Hitstop（卡肉） | 命中瞬間停頓 | 示範 **0.15 s（60fps＝9 幀；影片口誤說 6 幀）是刻意開大**；一般動作遊戲**一兩幀**。效果：「刀好像被什麼擋了一下」。**攻擊動畫、敵人動畫、傷害都不用改**。鈍器／拳頭可較長以凸顯鈍擊感與力量 |
| 7 節奏 | 快慢、時間扭曲、停頓 | 不是一直快；動畫有時間扭曲、打鬥中有停頓空隙。何時快、何時必須慢 |
| 8 處決動作 | 終結演出 | 「給玩家發獎盃」：換構圖、換鏡頭、慢動作、霸體、更誇張的特效與音效。數值與普攻差不多，差在勝利確認。依**武器／方向（正面背面）／可互動場景**有不同處決。只有一種處決＝打完敵人變布娃娃飛走，體驗差很多 |
| ＋ 觸覺 | 手把震動 | 片尾帶過，未展開 |

## 3. 本專案製作動作時的檢查表

做任何攻擊、受擊、處決動作或戰鬥回饋時，逐條自查並在回報中寫明現況：

- [ ] **動作**：有沒有預備（蓄力）→ 重心移動 → 肩帶臂 → 收招？武器重量看得出來嗎？（緣一的刀路／規格以 `緣一_全套動作製作規格_Claude交接_V1.0` 為準，本表不取代它）
- [ ] **受擊方**：被打的一方有沒有可見反應？輕／重是否不同？方向是否影響？
- [ ] **Hitstop 是畫面停格**：攻擊方與受擊方的**動畫都要凍住**，不是只停位移。量實際停了幾幀（60fps：1 幀 ≈ 16.7 ms）。
- [ ] **音效**：揮擊＋命中都有？同類有隨機池與音高偏移？重擊／特殊招是否另做？
- [ ] **鏡頭**：鏡頭震動依使用者既有裁定（一般震動已被要求移除，見下節）——**未經使用者同意不得自行加回**。
- [ ] **特效**：能否不看 UI 就讀懂發生了什麼（命中／被擋／彈刀／破防）？
- [ ] **節奏**：整段連招有沒有快慢與停頓？還是全程同速？
- [ ] **處決／忍殺**：有沒有和普攻不同的鏡頭、構圖或時間處理？
- [ ] 視覺結果只能給 `ART_REVIEW`，`ART_APPROVED` 由使用者決定。
