## 定位

以江戶時代日本村落為基礎，融合東方 Project 幻想風格，人類與妖怪共存的熱鬧村莊。
（與 `docs/village-art-direction.md` 的既定原則一致：可遊玩的幻想鄉，不是歷史博物館。）

- **中心：龍神廣場**——龍神像為全村視覺焦點（現行基線已有龍神像資產）。
- **廣場西側**：鈴奈庵。**廣場東側**：霧雨店。（兩者現行基線已存在。）
- **廣場往南**：市集・商業區主軸，鯢吞亭位於此軸上（娛樂區）。
- **西半部**：住宅區（安靜居住區，普通町家與農家）。
- **東半部**：稗田邸＋稻田・農家區（大片田地）。
- **北緣**：墓地；**東北**：寺子屋（現行基線已存在）。
- **南緣：河流（柳之運河）**——沿村南側繞行，多座橋跨河。

## 六種町家家族（重建住宅時的類型學）

| # | 類型 | 特徵 |
|---|---|---|
| 1 | 貧民町家（小型） | 生活簡樸、空間狹小；單身者或低收入家庭。1F＋小 2F |
| 2 | 普通町家（中型） | 一般家庭；格局方正，有庭院和生活空間。2F |
| 3 | 商人町家（大型） | 商人／店主的住宅兼店鋪；店面寬敞、後方居住。前店後居 |
| 4 | 富裕町家（豪邸） | 佔地大、建築華麗，有庭園和書房。含中庭 |
| 5 | 農家（帶農地） | 茅草屋頂；房屋後方有農地或菜園 |
| 6 | 長屋（連棟） | 多戶連棟（住戶A/B/C 共牆）；工匠或商人聚集區 |

## 建築元素庫

- **屋頂樣式**：切妻、入母屋、寄棟、茅草。
- **外觀元素**：格子窗、雨戶、暖簾（簾口布幔）、木製招牌、燈籠。
- **庭園・外構**：竹籬笆、石燈籠、水缸、小徑石階、植栽。

## 設計重點（概念圖原文）

1. 保持江戶時代日本村落的風格。
2. 建築材料以木材、土牆、瓦、茅草為主。
3. 結合東方幻想元素（符卡、燈籠、妖怪裝飾等）。
4. 營造人類與妖怪共存的生活氛圍。
