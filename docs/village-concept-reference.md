## 全村配置（依 `村落農村概念俯視.png` 重寫）

- **軸線**：一條寬闊市集主街貫穿村心，自南面大鳥居起，斜向北延伸至山丘腳下。
  街道兩側店屋連續、攤販外溢，形成商業走廊。**這是全村最主要的公共空間。**
- **視覺終點**：**北面林丘上的社寺**——多座紅鳥居沿坡而上，社殿踞於林梢。
  **全圖最強的地標靠「高程」而非建築高度取得。**
- **西半**：住宅區。密度自主街向外遞減，轉為獨棟、庭園、菜畦、竹林、溪流。
- **東半**：農田區，大片水田格網＋灌溉渠，其中座落一棟**華麗大宅**（＝稗田邸）。
- **東北**：河中平台上的**龍神像**；周邊有橋、田、散屋。
- **水系**：主河在北／東北；**細渠穿行村內**（尤其東側與中央），多座木拱橋跨越，
  渠上有**水車**。水既是灌溉與動力，也是分區邊界。

## 街道規格（自圖與 `住商地區.PNG` 實測）

- 主街：寬約 **8–14m**，兩側建築高 **6–9m**（含屋頂）→ **W:H ≈ 1:1~1.5**。
  足夠容納攤販與人流，但仍被建築確實圍合。
- 次街：3–5m，W:H ≈ 1:1 或更小。
- 巷道：1.5–3m，簷、籬、水路進一步壓縮。
- **樹木避開市集主軸**，集中於水邊、橋頭、社寺、住宅庭院。

## 地面

夯土為主，**主要動線與店前、濕區鋪不規則石板**。無路緣石、無人行道；
街面直接融入店先、排水溝、植栽與門檻。

## 建築元素庫

- **屋頂樣式**：切妻、入母屋、寄棟、茅草。屋頂形式與脊高**大幅變化**，
  大型旅籠／店屋用疊層屋頂；共通的深色瓦材維持整體統一。
- **外觀元素**：格子窗、雨戶、暖簾、木製招牌、燈籠、幟旗。
- **庭園・外構**：竹籬笆、石燈籠、水缸、小徑石階、植栽。

## 設計重點（概念圖原文）

1. 保持江戶時代日本村落的風格。
2. 建築材料以木材、土牆、瓦、茅草為主。
3. 結合東方幻想元素（符卡、燈籠、妖怪裝飾等）。
4. 營造人類與妖怪共存的生活氛圍。
