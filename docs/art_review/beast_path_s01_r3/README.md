## 視覺上改了什麼

**地表（第一優先）**
- 地表分區改由情境決定：樹冠群、林下、低窪、岩腳、村端→林內的梯度，再加上 domain warp。原本整片短草坪，現在拆成粗草塊、林床落葉、零星苔地、路旁被踩薄的裸土，以及乾、濕色差。
- 村端保留較開闊的短草，愈往林內，林床愈多。路旁的落葉帶用噪聲切成一段一段，避免沿路連成一條緞帶。
- 開闊地上的單叢灌木和蕨類會長在粗草裡，林內的則併入林床，不再像種在剪過的草坪上。
- 落葉用專案既有的 CC0 貼圖 `terrain_forest_*`，苔地用 `terrain_grass_*`。只在 S01 專用 shader 裡取樣；共用的 `bp_ground.*`（S04）和 P7 貼圖陣列都沒動。

**谷腳岩組 f02（第二優先），位置約 (55, −4)**
- 原本是一塊貼坡平躺的大岩盤（6.8×1.9×7.65 m，層理很重），下面再疊一片衛星板，看起來像人工疊起來的石板。
- 現在主岩改成插進坡裡、較高的岩塊：層理幾乎拿掉，層面斜傾，節理加深，岩腳的頂點 AO 不再那麼黑。順坡往下疊的那片板拿掉，改成沿等高線半埋的 3 塊。坡腳往下有一道碎石扇，和 5 顆半埋碎石連起來。岩腳的土、苔、落葉只畫在地表。
- 岩數：f02 從 2 顆變成 4 顆岩加 5 顆小碎石。沒有用堆更多岩去遮問題。碰撞體從 2 個變 3 個（S01 全區 16→17，上限 40）。

## 還沒解決的問題（直說）

1. **地表**：大方向對了，但還不到「完全自然」。
   - c40 右側和 c66 左側的路旁仍有成帶的褐色區。
   - 少數暗斑像是染在草上的污漬，c66 前景和 t30 右下較明顯。
   - 短草和林床之間的中間狀態還偏少，看起來仍有點二分。
   - 目前只靠地表著色，沒有加任何新的 3D 地被，因為授權要求「不加大量散佈物件」。
2. **f02**：已經不像疊石板了，但主岩右側還有一段短的暗色岩棚，量到下坡側有局部懸出：底面離地超過 0.5 m 的頂點有 27 個，最高 1.8 m。再往坡裡傾，就會開始像平躺的板。用現有的程序岩，大概只能到這裡；要更好，就需要谷壁局部幾何配合，見提案 A 段。
3. **谷壁**：短的水平岩紋和太平滑的坡面都還在。這一輪不處理，見提案。

## 谷壁幾何提案（未實作，等批准）

圖：`proposal_wall/P1_A_w30_back_l.jpg`、`P2_B_c56_back.jpg`、`P3_BC_w_obl_left.jpg`、`P4_profiles.png`（剖面為實際比例）。

**哪幾段**
- **A**：東壁 z +5 → −45（x 52–74，高約 22 m），是主空地回望時左側的壁，f02 就在它的腳下。**最小改動建議只做 A**。
- **B**：西壁 z +8 → −25，在鳥居前回望時社殿後方。
- **C**：西壁 z −40 → −80，側看時那一長段斜坡。

**做法**
- 沖蝕溝：順落水線切入 0.5–1.0 m，坡腳留小土石扇。
- 斜傾岩棚：凸出 0.6–1.2 m，傾 10–20°，刻意不水平、不連續，用來打斷現在的水平紋節奏。
- 岩肋：凸出 0.4–0.8 m。

**保留什麼**
- 只在坡度 ≥ 35° 的壁面帶內位移。
- 坡頂線往下 2 m、坡腳線往上 1.5 m 內漸變到 0，所以輪廓和谷底遊玩空間不變。
- 接縫 z < −90 不做，S01／S02 接縫不受影響。

**影響**
- S01 地形網格與碰撞檔會改變，所以 gate `isolation.s01_terrain_locked` 會**照設計 FAIL**，需要你核准更新 `s01_locked` 基準。gate 本身不放寬。
- 壁上的岩和樹要重新貼地：樹的 xz 不動，只改 y；櫻在谷底，不受影響。
- 主路和七條路線在谷底，不受影響。

**能不能程序化重現**：可以。由 layout 驅動、固定 seed 的 S01 專用高度修正，和現在的生成器同一條管線。上面「R3 開關」那項已經證明重生成是逐位元可重現的。
