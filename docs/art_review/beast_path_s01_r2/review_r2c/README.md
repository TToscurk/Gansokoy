## 看得出的改變

1. **谷壁**：原因是 46° 以上的坡面 100 % 塗同一層岩色，所以一整片灰褐。改成「落水線上的苔／草帶＋岩脊上的裸岩」交錯（沖溝、小台長植物，越陡越少，實體岩周圍留裸岩）；遠景細節層在陡坡上改用三平面取樣（原本的平面投影會把岩紋拉成縱向長條）；拿掉 2 組只剩一顆小凸起、像貼上去的岩。只改地表顏色通道與 S01 專用 shader，**地形高度與碰撞沒動**。
2. **群落**：沿用前一版的拆鏈；左側 37 % 那叢再往後退、疏一點。
3. **20–35 % 過渡**：右側田邊加一棵孤立的闊葉樹，把左右兩側拉平衡；拿掉兩處像擺上去的植物。所有灌木、羊齒腳下加一圈落葉／苔（不再像插在修剪過的草坪上）。
4. **櫻**：右側的垂櫻 sakura_b 再往外退（總位移 5.5 m，仍在 6 m 上限內），五棵都保留。
5. **擺放修正**：林下植物原本是以 loose 模式種的，規劃器不看道具，柵欄也只用柱子取樣，所以有一叢灌木長在田裡、一叢貼著柴堆。現在 R2 改用「柱到柱的線段」和道具腳印把它們清掉，總量仍是 380。

## 模型看圖的意見（不是驗收）

- 谷壁「天然谷壁」自評：R1 2／前一版 3／**本輪 4**（滿分 5）。已不再是一整片灰褐，讀起來是「岩面＋植被」。
- 群落：58–66 % 改善最明顯；左側分成前、中、遠景群，右側沒有長出新的帶。
- 過渡：25、30 % 本輪最好；35 % 的林蔭感模型認為 R1 略好。
- 16:00 路肩：鳥居下、90 % 兩處都比 R1 清楚，也沒有整體變亮的感覺。

## 仍然看起來人工的地方

- **谷壁岩面有短橫紋重複**，底下的地形是平滑的單一坡面。要真正解決得做中尺度的岩層、裂面、小台，也就是改地形，需要你核准。依「兩次不成就停」，陡坡材質我已停手（兩次嘗試：拿掉拉長、三平面遠景）。
- 坡腳左側那組層疊的大岩有點「疊石板」感。
- 地面整體太像修剪過的草坪（R1 起就這樣，屬於 S01 地表全區的問題，這輪沒動）。
- 櫻：右側仍有一點「一排花樹」的節奏，但已不像行道樹。前一版與本輪兩次調整後停手。
- 少數灌木、羊齒仍是「一叢放在那裡」的感覺。
