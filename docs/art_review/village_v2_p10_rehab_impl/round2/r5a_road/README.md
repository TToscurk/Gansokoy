# R5a ROUND 2 — Road Base Regeneration Pilot（小範囲・可重現）

狀態：ART_REVIEW（r2）。未 ART_APPROVED、未封存。D3 CONDITIONAL（最小作用域・可重現・快照＋依存確認）。全村の道は再生しない。

## 使用者 ROUND 2 指摘
錯誤田格の消除は受理。道路は「まだ広い・縁が整っている・滲透感がない」→ 地面デカールを足すのではなく小範囲の道路 base Pilot。優先：①地面からの浮き ②まっすぐ・等幅の路縁 ③土・草・砂利の滲透 ④区間ごとの使用摩耗。
参考写真：林と田の間の農道——曲がった不揃いの縁、草の侵入、露出した土、轍、田との間の細い水路。

## 根因（実測）
`gen_village_v2.gd` `_ribbon`：折線を 2 m ごとに取り、左右 2 点だけの平らな帯を「道の高さ＋0.10 m」に置く。
実測（`gate_plan_negatives.log`）：FarmPath_1 地形＋0.100（最大 0.171）、FarmPath_4 ＋0.100、南橫街 ＋0.106（最大 0.172）。半幅は一定、線は定規の直線、横断は平ら。

## 対象（3 本・合計 416 m）
`Roads/FarmPaths/FarmPath_1`（160 m）、`Roads/FarmPaths/FarmPath_4`（216 m）、`Roads/SecondaryRoads/CrossStreetSouth` の**橋より東の田の区間だけ**（x ≥ 330；町の区間の三角形 150 は元のまま逐字コピー、境目の行＝元の左右頂点 0.000 m）。

## 再生のやり方（overlay `RoadBaseP10`、`gen/road_base_p10.scn`、PropFixP10 の次）
- 1 m ごと・横 7 点、各点＝P1 地形（TerrainCollision 射線）＋持ち上げ：芯 +0.03／+0.045／+0.06（交差点で上下 ≥ 0.012 ＝ちらつき防止）、縁 −0.015（地形に潜る）。
- 半幅＝元 × 0.66–0.82（農道）／0.52–0.70（南橫街、橋のすぐ東から田へ絞る）× ゆらぎ、蛇行 ≤ 0.31／0.57 m；**元の路幅の中だけ**（|蛇行|＋半幅 ≤ 元の半幅 → P8 田・P9 地被・P6 店先の取り決めを越えない）。端・交差点の 6 m は蛇行・幅ゆらぎ 0。
- 区間ごとの使われ方 traffic（村の出入口 0.95 … 田の奥 0.12）を UV2.y＝1＋traffic に入れ、GroundPilotP10 の pilot shader（補丁 7 段目、UV2.y ≥ 1 の再生道だけ）が「轍＝草なしの土の帯／中央草／路肩の草の侵入／村側の砂利」を変える。旧網格（全村の道）は UV2.y＝0 → 見た目不変。
- 田埂道 1／4 の center_patch 1.0→0.35（沿路 7 m 周期の中央草の途切れが梯子状に見えた）。
- 元の網格が切れている所（南橫街 144–158 m＝橋）は切れたまま。
- runtime で MeshInstance の mesh だけ差し替え、材質は GroundPilotP10 のまま。`enabled=false` で元の mesh。**元の road_*.res は不変**（sha256：farmpath_1 `47c5492e008e…`、farmpath_4 `f46ba82e6212…`、crossstreetsouth `7f4e607d6139…`、build 前後一致）。

## 依存の確認（gate）
- 碰撞：対象の道に碰撞なし（歩行＝P1 地形碰撞）→ 玩家・NPC の歩行は不変。
- NPC：再生道の近く（元の半幅＋1 m）の NPC 0 人（人口・路線不搬）。足の位置と路面の差は 0.10 埋まり → 0.03–0.06。
- P8：元の路幅の中だけ（横距離 ≤ 元の半幅）→ 田・畦・水路に食い込まない。
- P9：元の路幅の中の地被／立ち草の株 0、地形から 6 cm 以上浮く株 0（非 headless で MultiMesh を読んで確認）。
- P7 橋：南橫街の橋（切れ目）を跨がない。P6：南橫街の町の区間は元の三角形。
