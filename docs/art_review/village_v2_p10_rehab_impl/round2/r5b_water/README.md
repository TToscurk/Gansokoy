## 根因（實測）
1. **白い縦材の正体**：WaterFX／架台／P5 LOD0 の表示切替で特定（`fxprobe*`）。
   - ① r1–r12 の手作り四角の巻き順が Godot の規約（時計回り＝表）と逆 → 方塊（柄杓・受け樋・架台・杭）が**裏返し**（外側の面が間引かれ、奥の内側の面が外向き法線で照らされる＝空の色の青灰に光る）。
   - ② P8 落とし樋（WaterSupply）の木部は頂点色なし＝輪（頂点色 0.607）の **1.6 倍明るい** → 支柱・樋が淡色の縦材に見えた。
2. **西から柄杓が見えない**：r1–r3 の柄杓は輪面と東軸承柱の 0.18 m の隙間（輪の輪郭の内側）。
