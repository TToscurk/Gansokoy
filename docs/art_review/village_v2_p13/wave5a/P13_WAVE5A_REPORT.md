## 0. 結論（先に）

使用者の問い：**P1 を触らずに、石垣は山坡に自然に融けるか。**

- **石垣の石組みと、土坡の周囲地形への馴染み：できた。** 近景 2→3〔左の石組みだけ 2→4〕、やや高い視点（右）3→4（下寄り）。いずれも P1 を触らず、overlay だけで達成。
- **石垣の最下端が土に「嵌まる」感じ：部分的。** 2→2〜3。長く追える接地線は崩れたが、**牆腳の暗い接触影**が残る。この影は材質ではなく光照由来で、土を増やしても減らない（2 回調整して変わらなかった）。
- **通常 TPS からは、改善が見えない。** 石垣の面は外向きで、路の上のカメラからは背面になる。変化した画素は 0.5〜1.1 %。評価は 4→4（微差）。
- 結論としては「**P1 の解凍が必要になる理由は、今回の範囲では見つからなかった**」。ただし、最下端の接地線を完全に消すところまで求めるなら、地形側〔石垣の根元の地形を不規則に隆起させる〕が最も効くので、必要なら最小範囲を別途提案する（§6）。

## 1. サンプル範囲

**s=58.95–64.20 m**（両側）。承認は「s≈59–63」。次の 2 点で幅を取った。

1. **下端 58.95**：両側とも run の境界。ここで W4B の旧石垣へ繋ぐ。土坡は下端側へ 1.0 m〔s=57.95–58.95〕だけテーパーして伸ばす。
2. **上端 64.20**：第二平台〔62.6–64.2〕を含めた。平台の壁は外側地形が笠石頂線まで上がって**自然に山坡へ収まる**〔露出 1.19→−0.08 m〕ので、サンプルが「壁の端の自然な終わり」を持てる。64.2 m より先へは何も出していない（gate G1）。

現場幾何（`probe_w5a_sample.gd`）：両側とも 0.2–0.8 m の短い run が約 15 個〔この分節が積木感の一因〕、露出 0.5–1.2 m、外側地形の外向き勾配 3〜4°（平台の端は逆向きに上がる）。

## 4. 残る問題（誤魔化さない）

1. **牆腳の黒い接触影**：石の下縁が土と接する所に暗い帯が残る。診断〔変化画素を面の種類で分類〕では、石の向きによる陰影と接触影の合成で、穴ではなく、土の量や色を変えても動かなかった。**根元の近接ではW4B より暗い面積が大きい。**
2. **笠石直下の黒い楔**：評審が毎回指摘した。診断画像で、笠石自身の側壁と下面〔下から見える〕が影で黒く見えるものと分かり、〔笠石の継ぎ目が外八に開いていた自分のバグ・隣り合う笠石の厚み差・側壁と下面の漸暗〕を直した。最終の評審でも「残る」と言われた。
3. **石の粒度**：大きさは混ざったが、似た寸法の多角形が続く。小さな詰め石はまだ足りない。
4. **様式の切り替わり**：サンプル下端〔58.95〕と、手前の W4B の大きな角石の間で作風が変わる。これは「局所サンプル」の性質で、整条に広げる時に解消する。
5. **通常 TPS では効果が見えない**（§0）。石垣の面が見える視点は、路から外れた近景・高視点だけ。
6. **草叢**：1 株しか入れていないので、「少量の草叢で接合を馴染ませる」は検証していない。
