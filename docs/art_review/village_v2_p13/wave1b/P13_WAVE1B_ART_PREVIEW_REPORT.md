## 3. 預覽啟動方式（不改 main.gd）
- 在編輯器開 `res://maps/village_v2/p13_preview.tscn` 後按 **F6**。
  - 也可以用命令列：`Godot --path godot res://maps/village_v2/p13_preview.tscn`
- 它會把正式 main.tscn 當成 current_scene 啟動、載入人間之里，再加上 overlay。玩家、相機、NPC、碰撞都是正式的。
- **F8**：切換預覽 ON／OFF。OFF 時還原每個節點原本的 visible。
- **F7**：依序跳到主街 → MKT_010 → MKT_006 → 農家。
- 一般 F5 不受影響。
- 切換自測：連續切 5 次，沒有出現新舊同時顯示或還原遺漏（0 處）。

## 4. 原 A1／A2 選址錯誤的根因（已查證）
- 稗田邸本體不在 greybox.json 裡；它是 landmark Hero。parcels.json 的 `P_LM_HIEDA` 只涵蓋本屋箱 386–420 × −52–−28。
- 宅邸範圍其實是大宅門延伸出去的圍牆（`hieda_wall` 的 plan_local，以門為基準），換算成世界座標是 **x 384.5–421.5、z −60–−10**。
- 上一輪 `farm_sites.py` 有三個問題：
  1. 只排除 greybox 建物的**中心點**距離。
  2. 完全沒有把圍牆範圍列為禁區。
  3. 候選位置也只檢查中心點。
- 量測結果：原 A1 (398, −11) 與原 A2 (383, −27) **都在圍牆範圍內**（距離 0 m）。
- 沒有發現座標轉換錯誤。
