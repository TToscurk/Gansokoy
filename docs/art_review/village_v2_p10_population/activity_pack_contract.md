# P10 R3c — NPC Activity Pack（條件式下一包；尚未開工）

## 前置順序
1. P10 R3b Population Pilot 完成 full regression＋independent check，提交 FINAL ART_REVIEW。
2. **只有使用者授予 R3b ART_APPROVED 後，才可開始 R3c。**
3. R3c Activity Pack 通過後，才開始 Village Core Population Expansion。

## 固定範圍
- 維持目前三區 **16 人**；不增加 NPC、不填滿 anchors、不擴全村。
- NPC Asset Library 維持 SEALED；新增 Activity 的載入位置須另行決定，不可默認改寫封存 NPC wrapper／clips／roster。
- 只使用 Mixamo 候選，不自製動畫。
- 目標是讓既有人物從站著／走路變成可辨識的生活活動，不是加人口密度或重做市集構圖。

## 優先候選搜尋
- Elderly / Old Man Walk
- Youth / light short-step Walk
- Talk / Conversation
- Carry Box / Carry Object
- Inspect / Browse
- Sit
- Drink / Eat

## 每支動畫的完成條件
- 先選代表性角色實機驗證，再決定整合；不用來源名稱、骨架結構或 headless gate 冒充自然度驗證。
- 驗證手臂、袖子、裙擺、道具與身體穿插；確認可接受接觸與真正貫通的區別。
- 優先自然、少穿模、少手修 key；不因一支候選失敗直接解封模型。
- 沿用既有 retarget／grounded pipeline，錄下實機證據後送 ART_REVIEW。
- Agent 不授予 ART_APPROVED；未通過不得轉人口擴張。
