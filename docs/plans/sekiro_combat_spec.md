## 2. 設計主軸：為什麼抄隻狼

隻狼的核心不是血量，是**軀幹（Posture）**：

> 打不死你，但我可以逼你破防。

這對本專案特別合適，理由：緣一的動作素材強在「刀的節奏」，而軀幹系統把勝負判定從「誰血多」搬到「誰的節奏被打斷」，正好吃這批素材的長處。

### 三條規則（不可妥協）

1. **架招不等於安全**：格擋成功不掉血，但**漲軀幹**。一直龜會自己爆。
2. **彈刀窗口極短**：命中前 0.15 秒內按格擋 = 彈刀（Deflect），自己軀幹幾乎不漲，反而灌敵人軀幹。
3. **軀幹滿 = 破綻**：破綻中被攻擊 = **忍殺（Deathblow）**，無視剩餘血量直接處決。

### 危攻擊（危）

紅色「危」字警示的攻擊**不可格擋**，只能：
- 突刺（突き）→ 見切（原地格擋鍵反擊）
- 下段薙掃 → 跳躍踩踏
- 抓技 → 側翻閃避

這是逼玩家「讀招」而不是「亂按」的關鍵，也是可玩性的核心。

## 3. 系統規格

### 3.1 Posture 元件（`combat/posture.gd`）

雙軌數值，玩家與敵人共用同一份實作。

| 參數 | 玩家 | 一般武士 | 說明 |
|---|---|---|---|
| `max_health` | 100 | 80 | 掉到 0 = 死亡 |
| `max_posture` | 100 | 100 | 滿 = 破綻（Vulnerable） |
| `posture_regen` | 25/秒 | 18/秒 | **血越少回得越慢**（隻狼核心手感） |
| `posture_regen_delay` | 0.8 秒 | 1.2 秒 | 受擊後多久才開始回 |
| `break_time` | 2.0 秒 | 3.0 秒 | 破綻持續時間 |

**血量對軀幹回復的懲罰**：`regen × (0.35 + 0.65 × health_ratio)`。血剩一半，軀幹回復只剩約 67%；殘血時軀幹幾乎不回，逼玩家不能只靠架。

### 3.2 防禦判定（玩家）

按住 `guard`（預設右鍵長按／可改鍵）：

| 情況 | 傷害 | 自己軀幹 | 對方軀幹 | 附加 |
|---|---|---|---|---|
| **彈刀**（按下後 0.15 秒內被打中） | 0 | +5 | **+22** | 火花、金屬撞擊聲、輕微 hitstop |
| **格擋**（持續按住） | 傷害 × 0.15 | +18 | +6 | 悶響、後退 |
| **未防禦** | 全額 | +12 | 0 | 受擊硬直 |
| **危攻擊被格擋** | 傷害 × 0.6 | **+40** | 0 | 格擋危攻擊代價很高 |

彈刀窗口 `deflect_window` 設為 @export，讓使用者自己調難度（0.05～0.5 秒）。

### 3.3 敵人 AI（`combat/enemy_samurai.gd`）

有限狀態機，不做行為樹（過度工程）：

```
IDLE ──玩家進入 detect_range──> APPROACH
APPROACH ──進入 attack_range──> WINDUP(前搖) ──> STRIKE(判定) ──> RECOVER(後搖)
                                      │
RECOVER ──> 隨機: 再攻擊 / 退開(BACKSTEP) / 繞行(CIRCLE)
任一狀態 ──軀幹滿──> BREAK(破綻, 可忍殺)
任一狀態 ──血量 0──> DEAD
```

**前搖必須看得見**：`windup_time` 預設 0.45 秒，武器抬起 + 身體前傾，玩家有時間讀招。前搖時間是 @export，讓使用者調節奏。

危攻擊：每次選招有 `perilous_chance`（預設 0.25）機率出突刺，前搖 0.6 秒 + 紅光 + HUD「危」字。

### 3.4 HUD（隻狼風）

版面：

```
┌────────────────────────────────────────────┐
│                                            │
│              ◆ 敵人軀幹槽 ◆                 │  ← 畫面上方中央，敵人血條在其下
│              ▁▁▁▁▁▁▁▁▁▁                    │
│                                            │
│                   危                        │  ← 危攻擊時，畫面中央紅字
│                                            │
│                                            │
│                            [ 忍殺 ]         │  ← 可處決時，敵人身上提示
│                                            │
│ ❤❤❤❤❤▁▁▁▁                                  │  ← 左下：玩家血量
│ ◆▁▁▁▁▁▁▁▁▁                                 │  ← 玩家軀幹槽
└────────────────────────────────────────────┘
```

視覺規則（照抄隻狼的可讀性做法）：
- 軀幹槽從**中央往兩側**長，不是從左往右——一眼看出離爆還有多遠。
- 軀幹超過 70% 開始**橙色脈動**，超過 90% 轉紅並加快脈動。
- 破綻時整條槽變成金色並閃爍。
- 彈刀成功時軀幹槽**閃白一下**——這是玩家判斷「我彈到了沒」的唯一即時回饋。
- 血量用分節（每 20 點一節），比連續條更容易讀出剩幾下會死。

### 3.5 鎖定（Lock-on）

沒有鎖定，隻狼式戰鬥不成立（讀招需要穩定視角）。

- 按 `lock_on`：鎖定最近的、在畫面內的敵人。
- 鎖定中：角色永遠面向敵人，攝影機保持敵人在畫面中。
- 敵人死亡或超出 `lock_break_range`（預設 20 m）自動解鎖。

## 5. 明確不做（避免過度工程）

- 不做技能樹、義手道具、貨幣經濟。
- 不做行為樹或 GOAP，敵人用 FSM。
- 不做網路同步。
- 不改既有移動／動畫架構，戰鬥系統以**加法**接上既有 `take_hit` 管線。
- HUD 用純 Control 節點與程式繪製，不做貼圖資產（避免美術債）。
