## 2. 遊戲中 HUD（ui_hud_1366 / ui_hud_1920）

- ~~A1~~〔已修〕**對話中血條/技能鍵疊在對話框上**（1024 寬最嚴重，
  1366 也擦邊）。對話框寬 `min(880px, 90vw)`，#vitals（左下）與
  #skills（右下）是固定位，窄視窗必撞。修法：`hud.js` 加
  `body.talking #vitals/#skills/#questToasts { opacity:0 }`（對話中
  本來就出不了招，顯示著只是干擾），並給兩者加 opacity 過渡。
- ~~B3~~〔已修〕**神社的按鍵提示列缺「K 技能」**：K 面板在神社按得開
  （loadout 掛的），但提示列沒寫 —— 玩家只能從其他地圖得知。
  修法：main.js 的 installHUD keys 補 `['K','技能']`。
- B｜右上角時刻/畫質字（11px、opacity .6）在正午亮天空下對比偏低。
  有 text-shadow 撐著，尚可讀 —— 列為觀察項，不動。
  若要改：opacity .6 → .75。
- C｜〔主觀〕底部按鍵提示兩行資訊量偏大，可考慮首次進圖 10 秒後
  淡出、按 H 喚回。不動也行。

## 3. ESC 選單（ui_escmenu_1366.png）

- ~~B4~~〔已修〕「快轉 3 小時」按鈕文字換行成兩行，與同排「恢復流動」
  高度不齊。修法：`.srow button` 加 `white-space:nowrap`。
- 其餘：hover 有回饋（紅底過渡）✓、風格統一 ✓。

## 4. K 技能面板（ui_kpanel_1366.png）

- ~~B2~~〔已修〕**右側出現瀏覽器預設的白色捲軸**，在墨色面板上非常
  突兀（「預設 HTML 感」的唯一來源）。修法：skillpanel.js 加
  `::-webkit-scrollbar` 樣式（8px、金色半透明 thumb）＋
  Firefox 的 `scrollbar-width/color`。
- 內容排版（主動技左、被動右、氣力/冷卻著色）清楚 ✓。

## 5. NPC 對話框（ui_talk_1024 → ui_talk_1024_fixed）

## 6. 讀取畫面（ui_loading.png）

- C｜〔主觀〕黑底＋「〇〇 讀取中／LOADING」功能上沒問題，但是

## 7. 大地圖（ui_map_1366 / ui_map_1024 / ui_map_labels_fixed）

- ~~B1~~〔已修〕**西北角山系四個節點（妖怪之山/守矢神社/天狗聚落/

  worldmap.js 加逐節點標籤偏移表 `LABEL_OFF`（守矢→右、天狗→下、
  霧之湖→右下）。
- 1024 寬 resize 後正常重繪、無壞版 ✓。
