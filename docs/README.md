## 歸檔規則

設計書「做完」就搬進 `archive/`（用 `git mv`，歷史還在）。
判斷標準：**內容已經活在程式碼或別的活文件裡，再讀一次不會改變任何決定。**

three.js 時代（`src/`）的計畫書全部在 archive —— 那條線已凍結，
Godot 版不吃那些檔案。
