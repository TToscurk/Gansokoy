## 二、視線數學（L2 修形規格）

- 基準：眼高 1.6m，站村中心龍神像廣場。
- **丘陵天際線仰角 ≤3°**：H ≤ 0.052×D（D=500m→≤26m；D=700m→≤36m）。
- **山窗鞍部仰角 ≤1.5°**：H ≤ 0.026×D——讓 L3 峰與 skybox 山帶完整露出。
- 忌單排等高「圍牆感」；稜線與主山稜線不平行、不同高。

## 四、深度技法（概念圖主視覺三招＋霧改造）

1. **空氣透視烘進材質**：近丘草綠有紋理 → 遠丘灰綠無紋理 → L3 山藍灰近剪影
   （Meshy 山材質 albedo 往天空藍灰偏 15–25%，山腳必藏於 L2 後，不得見底邊）。
2. **稜線錯落**：層層頂線可辨。
3. **霧帶接腳（霧改造）**：撤全場均勻濃霧，改**水平霧帶 y≈20–60**——
   山腳沒入霧中，觀者腦補距離；概念圖的霧就是山腰帶狀。

5. **B5 地面視角驗收**：新增村中心人眼高度 shotlist（四向）——遠景審查
   一律以地面視角為準（教訓：俯視鏡位騙人）。
