概念圖的地區構成（由外而內）：妖怪之山 → 河流・水利 → 農田・農家 →
村緣 → 住宅巷弄 → 商業街 → 市場・龍神像。時間設定：初夏〜梅雨、傍晚。

## 現況問題（本提案要解決的）

1. 現有 Vista／OuterTerrainTransition 山體是一張連體大 mesh：形狀單調、
   無層次、無深度；先前山坡上的樹已拆除（2026-08-26）。
2. **河插山洞**：v6 沙盒幾何讓 U 形河尾端直接切進山體（非 Claude 設計；
   山面上的深色條紋是 Claude 為擋天空破洞加的垂幕補丁，重做時一併退役）。
3. 全場均勻白霧壓平了距離感——概念圖的做法是**山腰霧帶**，不是全場霧。

## 深度技法（概念圖主視覺的三招）

1. **空氣透視烘進材質**：近丘草綠有紋理 → 遠丘灰綠無紋理 → 主山藍灰近剪影。
2. **稜線錯落**：丘陵頂線與主山稜線不平行、不同高，層層可辨。
3. **霧帶接腳**：山腳消失在霧帶裡，觀者自動腦補距離。

## 河的出口（取代穿山洞）

北側丘陵環留一道 **V 形河谷口**（層3 最低處），U 形河尾端收進谷中、
遠端沒入霧帶——river 從村外繞過、消失在山谷，不再打洞穿山。
（概念圖亦是河沿村外繞行。）

## 執行順序

1. 【批准後】退役現有 Vista＋OuterTerrainTransition 山體與垂幕補丁。
2. Claude 產出丘陵環 blockout（`tools/gen_basin_hills.gd`，參數：排數、
   高度帶、河谷口方位角）→ 固定鏡位 → **ART_REVIEW**。
3. 使用者 Meshy 產主山 → 依層4擺位（Claude 協助放置與比例）。
4. 霧帶改造（Environment：壓低全場霧、加水平霧層）→ 前後對照。
5. 河谷口與河尾端整形銜接。
