# 盆地遠景規劃（DESIGN 提案 2026-08-27，等 Human Art Review）

目標：站在人里任何位置環顧，讀到「被群山環抱的盆地」——用**四層視差**
取代單一遠景 mesh。skybox 抬升驗證成功後，Meshy 實體山從「環形全包」
縮編為「少數英雄峰」，其餘方位交給天空板。

## 一、四層視差架構

| 層 | 距離 | 內容 | 誰做 | 狀態 |
|---|---|---|---|---|
| L1 盆底 | 0–300m | 村台、田、河、綠帶 | 場景現有 | ✅ 有 |
| L2 丘陵環 | 300–600m | `BasinHills` 低緩草丘＋山窗 | Claude 修形 | 🔧 雛形已在，需壓高度＋開窗 |
| L3 英雄峰 | 800–1500m | Meshy 山 2–4 座錨點 | 使用者 Meshy | 🔧 已擺 3 座，需校位 |
| L4 天空板 | 無限遠 | 全景圖＋horizon_lift | ✅ 完成 | lift 由使用者手感定值 |

深度感來源＝層與層之間的**視差差**：走動時 L2 明顯移動、L3 微動、L4 不動。

## 二、丘陵環（L2）修形規格——視線數學

- 基準：玩家眼高 1.6m，站在村中心（龍神像廣場）。
- **丘陵天際線仰角 ≤ 3°**：丘高 H ≤ 0.052 × 距離 D。
  D=400m → H≤22m；D=600m → H≤33m。超過就會遮 L3/L4。
- **山窗（鞍部）仰角 ≤ 1.5°**：窗底 H ≤ 0.026 × D，讓 Meshy 峰與
  skybox 山帶從窗中完整露出。
- 丘形語言：緩圓、重疊剪影（2–3 排錯落），忌單排等高「圍牆感」。

## 三、山窗方位（依概念圖地理：由外而內，妖怪之山在北）

| 方位 | 用途 | 對應 |
|---|---|---|
| 北窗 | 主景窗：skybox 主雪峰＋妖怪之山錨點 | 概念圖「妖怪之山」 |
| 西北窗 | 已擺「妖怪之山2」(-779, -808) 正對 ✓ | 河童重工方向 |
| 西窗 | 已擺「遠景山」(-1394, -146) ✓ | 魔法之森方向 |
| 東側 | 不開窗——低丘＋開闊感（稻田・農家區） | 概念圖東=農田 |
| 南口 | **河谷出水口**：河從兩丘之間的低谷流出盆地 | 柳之運河去向 |

**南口同時解決「山開洞插河」**：河尾不再打洞穿山，改為在丘谷間
漸窄、以蘆葦帶＋薄霧收尾消失（視覺收束，不做真實出海口）。

## 四、Meshy 山方案修改（回應使用者判斷）

- **縮編**：不做環形全包。保留已擺 3 座＋至多新增 1 座北面主錨（妖怪之山
  主峰，若 skybox 主峰方位感不足才加）。
- 校位：「遠景 妖怪之山」目前 y=-296 沉得極深（僅露頂?）需逐座在山窗
  後方 800–1500m 校 y 與朝向；山腳必須藏在 L2 丘陵後，**不得見底邊**。
- 推遠處理：三座山材質加距離霧染（albedo 往天空藍灰偏 15–25%），
  與 skybox 色調銜接，避免「貼在丘陵後的模型感」。

## 五、執行批次（每批 ART_FAST＋固定鏡位＋停 ART_REVIEW）

1. **B1 丘陵修形**：BasinHills 壓高度到規格、開北窗／西北窗／西窗／南口。
2. **B2 Meshy 校位**：三座山對窗、校高、藏腳、霧染。
3. **B3 河尾收束**：南口谷地化＋蘆葦帶（用現有 reeds 資產）。
4. **B4 地面視角驗收**：新增村中心人眼高度 shotlist（東西南北四向），
   之後所有遠景審查以地面視角為準——這是本輪教訓：俯視鏡位騙人。

## 六、不做的事

- 不做環形 Meshy 山牆、不重建舊 Vista 大 mesh、不在山上撒樹
  （L3 山的細節由 Meshy 貼圖自帶）。
- 不動河道本體、村台、地標（另有其主）。
