### 第一階段：靈夢（shrine_v3）

- 資源：沿用 `characters/reimu/reimu.tscn`（Reimu r1–r3 模型、65 骨＋袴骨鏈、Mixamo 待機 clip、FaceFill），沒有重新建模。
- 包裝：`maps/shrine_v3/reimu_shrine_npc.tscn`，結構與 `maps/village_v2/reimu_npc.tscn` 相同（AnimatableBody3D＋`npc_life_actor.gd`＋`hero_id=reimu`＋膠囊 r 0.22／h 1.55），日後可直接交給 NpcLife director。神社目前沒有 director，所以只播待機、不走動。
- 站位：賽錢箱西側 (−1.35, 30.008, −16.95)，面向參道（+z）。
  - 與賽錢箱（x ±0.62）間隔 0.51 m；與吽形狛犬台座（z ≥ −16.19）間隔 0.54 m。
  - 距參道中軸 1.35 m。
  - 「拜訪」互動區（8×4×5 m）涵蓋站位。
- 寫入：`shrine_v3.tscn` 末尾加 `人物/靈夢` instance（6 行）；`tools/shrine_v3/build_scene.gd` 加 `add_npcs()` 步驟，重建神社時會保留。

### 第二階段：獸道連線

- `data/map_routes.json` 的 `portal_overrides`：
  - beast_path 傳送點 1（BOSS 戰後北出口 46, −441）→ `shrine_v3`
  - shrine_v3 傳送點 0（南口）→ `beast_path`
  - 兩份 meta 都是生成器產物（勿手改），覆寫放在路由檔，重生不會丟。
- 南口 → village_v2：沿用原 meta。
- **出口封印（刻意的暫行偏離）**：`ExitSealBlock`（bp_role=exit_seal）原設計是 BOSS 戰後才解除，但 BOSS 戰尚未實作，北出口因此走不到。`open_seals.beast_path` 在載圖後停用它的碰撞。BOSS 戰接入時刪除此項，改由 bp_unlock 旗標解除。
- 舊劇情不搬：beast_path 沒有任何舊互動點。

### 第三階段：人里出生點與傳送

- **根因**：阿求、小鈴的袖子模擬各帶一個 `Floor`（WorldBoundaryShape，layer 20），鋪滿整張人里，高度 y ≈ 1.69。`main.gd` 的 `_pt_ground` 射線沒設碰撞遮罩，把它當成地面，出生點、傳送點因此被量成「埋地 1.3 m」。
- **修法**：`_pt_ground` 改用玩家的 `collision_mask`。修後出生點 (224, 0.39, 160) 離地 +0.00 m。
- 傳送點：
  - 獸道 (224, 172)：y 改為路面實測 0.32。
  - 稗田邸 1F (398, 2)：大宅門前。
  - 香霖堂 (428, −205)：龍神橋東端。
  - 後兩筆由 `portals_disabled_p11r2b` 移回 `portals`；→trail 那筆保持停用。
- 共用室內圖回程：`hieda1f`／`kourindou` 的回程 target 仍寫 `slice`，由路由「群組記憶」送回最後實際到過的版本（從 village_v2 進就回 village_v2，從 slice 進就回 slice）。
- NPC 自主生活：五人照舊，未改 npc_life 任何檔案。
- 環境音：`scripts/ambience.gd` 的時段表原本只有舊圖 id，三張新圖都沒有蟲鳴（基準測試就失敗）。已補 `villagev2`／`beastpath`／`博麗神社` 三筆，音量沿用舊版同地點；三圖 playtest 環境音 ✓。

## 地圖路由（`systems/nav/map_router.gd`＋`data/map_routes.json`）

| 驗證 | 目標必須有 `data/<id>.meta.json` 且不是目前這張圖，否則退回原值（防循環、無效目標） |

### 舊存檔相容策略

1. **預設 legacy**：存檔照舊讀到舊圖、舊座標，零變化。
2. **切到 v2 後**：`trail`／`slice`／`shrine` 存檔 → 換成新圖，**不沿用存檔座標**（屬於舊圖，會落地下或牆裡）。改落在新圖 `meta.spawn`（沒有就用第一個傳送點旁），等一個物理幀再量地面。實測三種舊存檔都落在新圖地面，離地 +0.00 m。
3. 任務、旗標原樣保留；新圖沒有舊劇情觸發器，所以不會重新觸發 MQ00／02／03、MQ07–12（已驗證：三張新圖的觸發器掃描為 0；往返一輪後任務、旗標不變）。
4. 未處理：舊任務的指路（WaypointResolver）在新圖會顯示「前往 獸道」並指向第一個傳送點。新劇情要一併換成新任務資料。
