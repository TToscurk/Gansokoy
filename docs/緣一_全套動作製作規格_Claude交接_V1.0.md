## 3. 用人話定義緣一，再轉成參數

### 3.1 整體觀感

> 他不是拚命把刀揮快，而是身體早已站在對的位置；刀一出，事情就結束了。

| 人性化用詞 | 工程／動畫落地方式 | 避免 |
|---|---|---|
| 沉穩 | 頭部視線穩、重心先落腳、預備動作小，動作結束可控制 | 像醉漢左右搖、每步彈跳 |
| 突然 | 預備與斬擊採不同時間密度，速度峰值集中在命中段 | 整支 clip 一律乘 3 倍 |
| 刀很準 | 明確目標點、刀刃沿刀路、刀尖與軀幹協同 | 刀背拍人、手腕亂扭 |
| 有重量 | 腳→髖→胸→肩→肘→手→刀依序傳力，隨揮被腿與軀幹接住 | 只有手臂像風扇轉 |
| 不拖泥帶水 | 命中後仍保留短隨揮，之後明確殘心 | 刀打到人就瞬間停格 |
| 收得住 | 終姿可銜接下一招、格擋或移動，腳底不突然換位 | 強制每招淡回同一 Idle |
| 呼吸感 | 胸腔／肩帶細小起伏，骨盆不跟著上下蹦 | 全身等幅正弦波 |
| 袖子跟得上人 | 軀幹／手先動、衣料稍後，停刀後衣料再衰減 | 靠穿模或誇張擺動掩飾關節 |

## 4. 共用量測、座標與時間契約

本節除明示既有值外，均為 `PROPOSED` 技術規格。

### 4.1 動作製作前必須量到的量

| 記號 | 定義 | 用途 |
|---|---|---|
| H | 中立站姿鞋底到頭頂高度，m | 尺度與鏡頭 |
| L_arm_R/L | 各側肩關節到腕關節的骨鏈長，m | IK 可達性，左右分別量 |
| L_blade | 鍔附近刀身起點到刀尖的中心線長，m | 出鞘、掃掠判定 |
| L_grip | 可用刀柄長，m | 雙手是否放得下 |
| R_grip | 實際握位截面的刀柄半徑／非圓截面尺寸 | 指形接觸 |
| S_hand／S_sheath | 手上刀與鞘中刀的有效世界尺度 | 換手時不能變大變小 |
| M_socket | 真正套用的骨相對插槽矩陣 | 禁止憑 Euler 猜刀軸 |

先做 IK reach budget：每側肩到腕目標距離建議不超過該側骨鏈長的 95%；95–98% 標警告，超過 98% 必須調整軀幹、鞘引き或步法，不能拉伸骨架硬達標。這是製作保守值，不是人體生理定律。

### 4.2 規格座標

- 本文以角色語意座標說明：`R` 向角色右、`U` 向上、`F` 向面前敵人。角度方向一律以角色自身左右敘述，不依鏡頭左右。
- 目標基準點為當前角色地面投影；`U=1.0 m` 代表離地 1 m。
- 實作前量出模型／骨架／Godot 的實際 forward、up、刀長軸、刀刃方向並寫出轉換矩陣。**本文不指定 Godot 節點必須朝 +Z 或 -Z。**
- `blade_edge` 定義為「刀的長軸垂直截面內，指向利刃一側的向量」；`blade_flat_normal` 是刀面法向。不可把兩者混用。
- 所有角度皆先指定父空間／角色空間／世界空間；文件中的身體轉角為相對中立姿勢的角色空間角度，不是待照抄的 bone-local Euler。

### 4.3 時間

- 新製作主時間以**秒**為準；建議動畫工作時間軸 60 fps，既有 24／30 fps 來源不擅自重解讀。
- `p=t/T` 為**當前單招／單段**有效播放進度；T 是以目前播放倍率計算後的實際秒數。
- 全文窗口用半開區間 `[start,end)`；`p=1` 為終姿，不再觸發傷害。既有 code 若採含尾端的幀窗，必須明確轉換，不默默改慣例。
- 實際時長 = 原始 clip 所選區段秒數 ÷ 有效播放倍率。不得對已 time-warp 的 clip 再重複套倍率。
- 索引從 0 開始：事件幀 = `round(event_time_seconds * fps)`。總採樣含終點時為 `round(T*fps)+1`，不可把採樣數直接當 duration frames。
- 斬擊、位移、刀光、命中、取消共用一個 action clock；慢動作／停幀要說清楚哪些時鐘一起暫停。
- 跨 tick 事件以「前時間到新時間是否跨過門檻」處理；不能只判斷某幀恰好等於某個浮點值。

### 4.4 共用製作目標：不是本輪實測

| 項目 | 第一版目標 | 測法與例外 |
|---|---|---|
| 握位位置誤差 | 主斬期間 p95 ≤ 0.010 m，max ≤ 0.020 m | 實際掌握錨點到目標握位；指骨距離不可冒充表面接觸 |
| 刀身穿掌／軀幹 | 可見刀身不得穿入掌心或軀幹 | 逐格幾何＋近景；鞘內刀身不算穿模 |
| 刀刃方向 | 有效切削段，切削方向與刀刃側向投影夾角 ≤ 30° | 排除近零速、刀尖方向突刺與過渡格；先定義投影平面 |
| 站立腳底 | 平地主要承重面相對地面 ±0.005 m | 鞋底網格，不是 Foot 骨位置；斜面量相對地面 |
| 接地腳滑移 | 每次鎖定的支撐區間總世界位移 ≤ 0.020 m | 分開記錄腳跟／腳尖換樞軸；不可把合法 pivot 當滑步 |
| 循環接縫 | 同側接觸點位置差 ≤ 0.005 m，主要關節角差 ≤ 3° | 另外檢查速度連續，不只比首尾姿勢 |
| 換刀可見性 | 可見刀恰一把；交接位置差 ≤ 0.005 m、方向差 ≤ 2° | 刀鞘中的遮蔽部分分開計算 |
| 取消連續性 | action time 不倒退；無重播事件、無重複傷害 | 同時回看手腕與刀尖軌跡；不能只看時間數字 |
| 機械關節 | 無肘膝反折、無腕部瞬間翻面 | 除去骨軸 roll 後量解剖相對角，再配圖審 |

任何門檻無法合理達成，回報實測與原因；不能放寬後仍冒稱原門檻 PASS。

## 5. 基礎移動與生活動作

### 5.1 動作清單與觀感

以下時長／範圍為提案。移動速度先保留第 1 節的有效專案值，量步態後再決定是否變更。

| 動作規格 ID | 人話要求 | 時序／參數起點 | 接續 |
|---|---|---|---|
| `idle_sheathed` | 站得鬆，但不是垮掉；不一直東張西望 | 3–5 s 呼吸週期；肩部起伏約 0.005–0.015 m | 任意移動／拔刀 |
| `idle_drawn` | 刀在可即時反應的位置，不端著重物發抖 | 同樣輕呼吸；刀尖微動以 ≤0.03 m 起步 | 格擋／斬擊／移動 |
| `walk_sheathed` | 正常沉穩走，不小碎步也不貓步 | 完整左右腳週期約 0.85–1.15 s，先按步速公式配速 | 起停／轉向 |
| `walk_drawn_f/b/l/r` | 面向敵人進退，腳有支撐、刀不跟著左右亂掃 | 分方向量步長；側移不可直接鏡像帶刀手的全身 | 輕攻擊 upper 層 |
| `run`／`sprint` | 快在前進效率，不是頭上下狂甩 | 胸前傾約 5–12°／10–18°，以當前素材可達性為準 | 減速／急轉／跳 |
| `start`／`stop` | 先蹬地、停時用腿接住慣性 | 起步 0.12–0.22 s，停步 0.15–0.30 s | 不強制鎖住所有輸入 |
| `turn_90`／`turn_180` | 腳換支點再轉身，刀不掃過自己 | 約 0.25–0.45 s／0.35–0.60 s | 保持移動可控 |
| `jump_start` | 小幅沉膝後離地，視線不望天 | 預備 0.12–0.18 s；離地事件與物理起跳同時 | 空中 |
| `air`／`land` | 空中有慣性，落地膝髖吸震 | 空中等實際接觸；落地恢復 0.15–0.30 s | 有移動可早接腿部 |
| `meditate_in/loop/out` | 慢慢坐下，安靜呼吸，再自然站起 | 入 1.5–2.5 s；循環 4–6 s；出 1.2–2.0 s | 受擊中斷依現有系統 |
| `get_up` | 手與腿確實支撐，不能像殭屍直接折起 | 1.0–1.8 s | 起身完成回對應站姿 |

二段跳、踩牆、攀爬等現有能力不刪除；本輪全套製作先保留接口與現有內容，不因「整套」就擴張成新的跑酷系統。

### 5.2 步態配速：一定要做，不靠感覺亂調

- `native_speed = 每個完整左右腳週期前進距離 / 週期秒數`。
- `play_rate = 實際地面水平速度 / native_speed`。
- in-place clip 以支撐腳相對 root 的後移量重建步速；不要因 root 無位移就認定步速是 0。
- 目標先控制 play_rate 約 0.85–1.20；超出太多時重新配素材／步長，不用狂播救滑步。這是審美建議範圍，非硬體限制。
- 走／跑／疾跑分開測，也測低速起停與側移。沒有物理前進的原地腳動畫，不算完成 locomotion。

## 6. 握刀、拔刀、快速拔斬與納刀

### 6.1 持刀基準

人話：**右手是握住刀柄，不是把刀黏在拳頭旁；左手握柄尾時，整隻手有承力，不是兩根手指摸一下。**

- 先量刀柄與手掌接觸，再解手臂 IK；刀柄尺度錯了，先回報，不能靠捏扁手指救。
- 雙手間距起點可參考 0.10–0.16 m，但最後必須受實際 L_grip 與手寬限制；放不下就回報，不能超出柄尾。
- 手指的掌指／近端／遠端關節分別彎，不把整根手指當一條棍子折。
- 手指閉合度做診斷控制：0 為本角色自然放鬆、1 為實際握柄，不等於把全指統一旋轉到同一角度。
- 單手、雙手、左手控鞘、空手四種接觸狀態明確標記，避免所有狀態左手都被 IK 拉向刀柄。

### 6.2 普通拔刀 `draw_sword`（提案 T=0.85 s）

| p | 人話／動作 | 事件 |
|---|---|---|
| 0.00–0.18 | 右手接近柄，左手扶鞘口，肩不先聳起來 | 右握權重平滑增加 |
| 0.18–0.70 | 右手拔出、左手鞘引き；軀幹配合，不硬伸肘 | 刀沿鞘口可行軌道；未出鞘部分遮蔽 |
| 0.70–0.85 | 刀已離鞘，移往備戰架勢 | 切至持刀狀態，左手離鞘或改雙手握 |
| 0.85–1.00 | 刀、手、胸口收穩 | 返回持刀 Idle 或移動 |

普通拔刀不開傷害。允許邊走邊拔時，腿維持 locomotion；若素材需大轉體或大步法，先提供原地全身版，不把下半身強剪掉。

### 6.3 快速拔刀逆袈裟 `quickdraw_kesa`（提案 T=1.80 s，不含額外長按蓄力）

人話：**先靜下來、左手把鞘帶開，刀一離鞘便斜上切過去；人沒有在原地轉圈。切完留一口氣，再把刀收回。**

| p | 階段 | 製作要求 |
|---|---|---|
| 0.00–0.20 | 備戰／握柄 | 重心下降約 0.03–0.06 m；右手不瞬移 |
| 0.20–0.34 | 真正出鞘 | 以刀身中心線、鞘口與可達性限制右手；左手鞘引き是主動動作 |
| 0.34–0.46 | 逆袈裟主斬 | 從角色右下斜往左上，切削段開窗；是否需反向以實際持刀解確認 |
| 0.46–0.60 | 隨揮 | 腳與髖把慣性接住，刀不停在敵人體內 |
| 0.60–0.70 | 殘心 | 視線留在敵人，不立刻低頭看刀 |
| 0.70–1.00 | 納刀／歸架 | 刀尖先對鞘口，沿實際鞘軸進入；完成後才釋放握刀 |

- 傷害窗提案 `[0.34,0.46)`；必須以實際刀已離鞘且刀刃有切削速度再收窄，不允許刀還在鞘裡就打人。
- p≥0.70 可接受移動，把剩下納刀轉 upper 層，但保持原 action time，不能從前一個切片重播。
- 想把出鞘段變水平，先重算臂展＋鞘引き＋骨盆轉向；禁止只改插槽旋轉。
- 主斬後按攻擊可提案改為保留持刀，走對應持刀終姿；這會改目前自動納刀流程，需另外列行為差異，不能偷偷做。

### 6.4 納刀 `sheathe_sword`（提案 T=1.00 s）

- 大致順序：把刀收近 → 左手確立鞘口位置 → 刀尖對口 → 沿刀弧逐步送入 → 鍔到口 → 握手放鬆。
- 不建議把拔刀直接反播當最終版本；可先重用做技術基線，納刀視線、停頓、握位須獨立檢查。
- 交接時計算手上刀與鞘中刀的**世界矩陣與有效尺度**；兩個節點各自看起來正確仍可能切換跳位。
- 衣料或特效遮住鞘口不算驗證；額外用診斷近景，不把診斷隱藏袖子的畫面當正式美術圖。

## 7. 普通攻防：先讓沒有日之呼吸的角色也成立

### 7.1 輕攻擊三段（提案）

共通：不是每刀都抬過頭；第一刀建立節奏，第二刀接原來的回勢，第三刀明確收束。原地用既有 lower 層承接步法；移動時採可行的上半身版本。

| ID | 人話與刀路 | T | 傷害 p 窗 | 接下一刀 p 窗 | 腳與身體 |
|---|---|---:|---|---|---|
| `light_01` | 從角色右上向左下，短促斜切 | 0.50 s | [0.18,0.31) | [0.35,0.65) | 小踏前 0.10–0.20 m；髖先轉，手再送刀 |
| `light_02` | 承接低位，由左下回到右上，不重置抬刀 | 0.55 s | [0.18,0.32) | [0.35,0.65) | 利用重心回換，不把腰硬擰超過可行範圍 |
| `light_03` | 清楚的一刀橫／斜收尾，斬完站得穩 | 0.65 s | [0.20,0.34) | [0.50,0.72) | 收勢比前兩刀長，不強制自動接旋轉技 |

注意：目前所有普通連段共用的取消值未必支援第三段獨立窗口。若先維持共用 `[0.35,0.65)`，要把第三刀真正切完放在 0.35 前；不能只改文案或動畫卻不改控制器契約。

### 7.2 重斬與蓄力

| 動作 | 人話 | 提案 |
|---|---|---|
| `heavy_cut` | 不是巨劍砸地；短暫蓄勢後，整體向一條斜線切入 | T=0.95 s，預備 [0,0.28)、切削 [0.28,0.43)、隨揮 [0.43,0.62)、殘心至結束 |
| `charge_in` | 人慢慢靜下來，並非原地抖動集氣 | 進架勢 0.25–0.40 s；長按滿蓄先沿用有效專案值 |
| `charge_hold` | 刀與視線穩定，呼吸小，衣料可微動 | 獨立循環；任何維持時長都不能慢慢滑腳 |
| `charge_release` | 一次爆發，衝到合適距離時刀剛好切過去 | 位移先沿用現有控制器；刀速峰值與接近目標同時 |

- 短按重斬、長按蓄力、收刀快速拔斬是不同進入條件，不要混成同一個「居合」名稱。
- 長按未滿放開、蓄滿不放、蓄滿放開、途中受擊、沒目標、目標消失、前面有牆都要有確定結果。
- 「衝刺距離 0」必須真的原地出刀；不能在除法或正規化時出錯。
- 傷害只在有效切削窗，抬刀、蓄力、納刀與純殘心不開傷害；刀光主生成窗與傷害分開定義。

### 7.3 格擋、彈刀、反擊

| 動作 | 人話 | 提案時序與尺度 |
|---|---|---|
| `guard_in/hold/out` | 把刀放到能接攻擊的位置，不縮成害怕的姿勢 | 進約 0.12–0.20 s；保持可循環；出約 0.12–0.18 s |
| `block_impact` | 接住了，但身體知道有衝擊 | 0.25–0.35 s；肩、肘、膝吸震，後退由碰撞安全的程式位移決定 |
| `deflect` | 短短一撥，把對方的刀帶離線 | 0.18–0.25 s；刀路約 10–25° 的可讀偏轉，避免整圈大揮 |
| `counter` | 彈開那一刻，刀自然回到攻擊線 | 先讀現有 `counter_window=0.5` s 與 legacy 11 行為；不要默改成另一型 |

邏輯彈刀窗若先於視覺刀到防禦位置，必須調整起始姿態或進場時序，不能只用火花掩飾。格擋迴圈中連續被打，也不能每次重新從空手抬刀。

### 7.4 閃避、受擊、崩潰、死亡與處決

| 動作 | 人話 | 製作起點 |
|---|---|---|
| `evade_step_f/b/l/r` | 快速移出攻擊線，頭部不用大翻轉 | 可選新增內容；0.35–0.50 s、0.8–1.2 m。**這會改現有翻滾選擇，不預設替換** |
| `roll` | 必須保留現有操作，翻完腳回地上、刀不穿頭 | 沿用現有 3.2 m 預設再量；全程測刀與鞘的清除距離 |
| `hit_small_f/b/l/r` | 疼但仍能控制身體，不每下都飛走 | 0.25–0.40 s；方向由攻擊來向決定 |
| `stagger_f/b/l/r` | 防線真的破了，重心丟失後才找回來 | 0.8–1.3 s 起點；最終配合現有 break_time |
| `death` | 支撐失效，倒地後不再彈回站姿 | 1.3–2.0 s 起點；結尾保持，死亡阻止攻擊事件 |
| `deathblow` | 靠近、確立對位、一次乾淨收尾，不隔空做處決 | 1.0–1.5 s 起點；玩家與敵人配對，實際接觸時結算 |

處決不是單獨播放玩家動畫就完成：要驗證雙方相對位姿、目標死亡／失效、牆邊空間、取消與鏡頭退回；不擅自新增傳送穿牆。

## 8. 日之呼吸：逐招製作卡

**本節全部為 PROPOSED；連續畫面參考仍為 REFERENCE_PENDING。** 型號依第 2 節本文參考標籤，不是既有程式陣列索引。

共通規則：T 是最終實際時長，p 是該招進度；每招清楚拆成預備→主動作→隨揮→殘心。表列傷害窗是候選窗，必須再用實際刀路檢查，不等於整段都能命中。距離指程式根節點位移，不可拿手腕伸展代替。

### REF01 圓舞 `sun_enbu`

- **人話**：用一個乾淨的圓弧把面前切開。弧線是刀走出來的，不是角色像陀螺轉一圈。
- **提案 T**：0.72 s；可原地或向前 0.20–0.35 m。
- **p 0.00–0.20 預備**：刀收在角色右上／右側可發力處，骨盆先建立支撐。
- **p 0.20–0.42 主斬**：向左前下方畫單一圓弧，角色正面平面內的弧掃角約 120–180°；實際半徑由臂展＋刀長決定。
- **p 0.42–0.62 隨揮**：胸口與髖逐步減速，刀移至左側低位。
- **p 0.62–1.00 殘心／出口**：可回中段或接同一低位起手的下一招。
- **傷害窗**：[0.22,0.42)；單一 hit group。
- **分層**：原地有腿部承力；移動版可 upper，但不可保留原本全身大轉體的上半身硬扭。
- **禁忌／驗收**：不得是水平轉圈素材換紅色刀光；關特效仍看得到完整圓弧。

### REF02 碧羅之天 `sun_hekira`

- **人話**：把刀帶成一個完整圓，順著身體旋轉一口氣切完；不是兩手攤開的空轉。
- **提案 T**：0.95 s；根位移 0–0.25 m。
- **p 0.00–0.22**：沉膝，刀到可接完整圓的位置。
- **p 0.22–0.62**：刀路在角色 F-U 縱向平面形成約 300–360° 的圓；以可達性決定身體轉動程度。
- **p 0.62–0.82**：踏穩／回正，吸收旋轉動量。
- **p 0.82–1.00**：回可防禦的中段。
- **傷害窗**：[0.25,0.62)；第一版同目標一圈只結算一次。
- **分層**：full；若要包含完整身體翻轉，另外做 takeoff／landing，不可把無離地支撐的倒立當地面姿勢。
- **禁忌／驗收**：先看連續參考再決定「身體到底翻多少」；完整刀圓不等於人必須空翻。

### REF03 烈日虹鏡 `sun_retsujitsu`

- **人話**：比圓舞更寬的一道 C 字斬，像把面前一整片攻擊線掃開。
- **提案 T**：0.82 s；根位移 0.15–0.30 m。
- **p 0.00–0.22**：身體側開但視線留在敵人。
- **p 0.22–0.50**：在身體前方 R-U 平面畫較寬 C 弧，提案 180–240°；刀路不穿過頸部。
- **p 0.50–0.72**：重心移回可站穩的位置。
- **p 0.72–1.00**：保留側向終姿，準備反向斬或格擋。
- **傷害窗**：[0.24,0.50)；單 hit group。
- **分層**：full 起步；僅在量得腰部旋轉可行後製作移動版。
- **禁忌／驗收**：範圍變寬靠步法、姿態與刀路，不靠縮放刀本體或傷害圈。

### REF04 幻日虹 `sun_genjitsu`

- **人話**：敵人以為抓到他，人已從攻擊線旁邊移開，留下短暫的錯覺。重點是避線，不是滿畫面分身。
- **提案 T**：0.68 s；側向根位移 0.8–1.2 m，受牆面碰撞裁切。
- **p 0.00–0.16**：小幅壓低重心，眼睛仍追敵人。
- **p 0.16–0.48**：斜側跨步＋身體轉向 90–180° 的可行提案；不是無限瞬間 360°。
- **p 0.48–0.70**：腳落在攻擊線外，刀回到反擊準備位。
- **p 0.70–1.00**：維持朝向敵人的出口。
- **傷害窗**：第一版預設空；若根據參考或使用者要加反斬，另作一個有刀路的傷害段，不靠分身自動命中。
- **分層**：full；無敵窗先用可調提案 `[0.16,0.48)`，不能與視覺避開攻擊混為一談。
- **特效／驗收**：提案 2–3 個短壽命殘影、0.08–0.14 s；關掉殘影仍有真實位移。原地播身體動畫不算完成。

### REF05 火車 `sun_kasha`

## 9. 狀態、銜接與事件契約

### 9.1 沿用分層，不建立第二個角色控制器

概念：`loco → 可選 lower combat → upper actions → full actions → 受控握位修正／衣料`。

這是對現有設計的整理，不是要求按字面新增同名節點。握位與衣料 modifier 真正執行順序須在引擎內確認，不能只由場景 child index 猜。

| 情境 | 下半身 | 上半身／全身 | 規則 |
|---|---|---|---|
| 收刀移動 | loco | 空手移動 | 刀只在鞘 |
| 持刀移動 | drawn loco | 持刀握位 | 單／雙手權重依 clip |
| 原地普通斬 | lower combat | upper | 同一 action clock |
| 跑動普通斬 | loco | 可行的 upper 版本 | 不保留不可能的大轉腰 |
| 快速拔斬／大型型 | full 接管 | full | 必要支撐期限制移動 |
| 納刀尾段移動取消 | loco | 同時間點 upper tail | 不倒退、不重新出鞘 |
| 受擊／崩潰／死亡 | 既有 full／反應路徑 | 同左 | 清理舊傷害／刀光／握刀事件 |

### 9.2 中斷優先序（提案，實作前和既有行為核對）

死亡／場景強制控制 > 軀幹崩潰與可中斷受擊 > 當前已承諾的切削窗 > 合法取消輸入 > 一般移動／待機。

- 對話／過場的 input lock 與受擊硬直計時器分開；不要為了受擊把 UI／對話整套鎖住。
- 「可按下一刀」與「當下立刻切下一刀」不同。先緩衝、到合法出口才消費；過期輸入清掉。
- 每次 action 結束／被中斷都清理該 action 自己的 hit group、位移、刀光生成與暫時權重，不能污染下一招。
- 對取消不是只看畫面：記錄舊／新 action time、刀可見狀態、左右手接觸狀態與事件觸發次數。

### 9.3 取消與輸入矩陣（PROPOSED，非現行行為宣告）

所有新取消規則須在 P0 和既有規則對照；使用者未授權改行為時，保留舊規則、標示差異，不默默套表。下表補足製作卡的出口契約。

### 9.4 空中時鐘與落地 barrier

第 8 節固定 T、p 只描述標準展示段；runtime 必須區分以下階段，仍以同一 action 執行個體統一管理事件：

1. `AIR_ACTION`：局部 action clock 前進，僅對跨過的傷害／刀光門檻觸發一次；物理重力與碰撞正常。
2. `WAIT_CONTACT`：需要落地的型完成空中斬與姿態回正後，若未接觸地面，停在**非傷害**可延長姿態／循環；局部動畫進度不跨入落地段，所有舊傷害窗強制關閉。物理時間、碰撞與獨立等待計時器持續，不能把角色凍在空中。
3. `LAND_RECOVER`：收到實際地面接觸後，從落地子段自身的 t=0 播恢復；不重播 AIR_ACTION。該子段沒有原先空中刀的傷害事件。恢復至合法出口才解除落地 barrier。
4. `AIR_EXIT`：本來允許空中接續的 REF06／10 可走明確空中出口，不必假裝落地；下一招必須 allowed_airborne，否則等接觸。

REF05 預設在標準 p=0.64 空中主動作完成後檢查接觸；REF09 在 p=0.74 回正後檢查。過早觸地／碰頂使原刀路不可行時，中止剩餘空中傷害，轉既有落地／受阻出口，不強播穿地。

等待上限提案 2.0 s：仍未落地就退出型，交還既有 Fall，不傳送、不補傷害、不直接宣布 grounded；死亡／場景退出立即清理。對應「等到落地才算結束」的序列器不得把單純 T 到期當下一型起點。測試至少包含早落地、晚落地、永不落地與等待中受擊。

## 10. 刀光、火焰、聲音與鏡頭：為動作服務

- 第一輪先關掉特效，確認本體。最後才接既有 trail／ignite／sun_dragon／hit_feedback。
- `trail_emit`（是否產生新刀光）與 `trail_lifetime`（舊刀光還活多久）分開；命中窗關掉不一定要把殘留火焰瞬間切掉。
- 普通斬刀光殘留提案 0.08–0.16 s，型 0.15–0.30 s；目前表內可能更長，調整前先拍對照，不一口氣蓋全部數值。
- 火焰沿真實刀身／刀路生成，刀根不疊白球，不用全畫面過曝代表威力。
- 揮刀聲在刀速上升段；打擊聲由真正命中事件觸發，揮空不能播命中音。
- Hit stop 提案普通命中 0.025–0.045 s、重斬 0.045–0.070 s；不得讓同一刀多個碰撞回呼疊成長時間停格。
- 鏡頭不得靠大幅震動遮腳滑／刀穿模。先用固定 gameplay camera 審本體，再加回饋。
- 關閉 VFX／鏡頭震動的滑桿值 0 必須完全有效，不可留隱藏的最小強度。

### P0 現況盤點：只讀

4. 建立第 2 節 mapping 與 usages 清單，不改編號。
5. 回報現況與本規格落差，選定**一個**既有候選為製作基準。若與本文件 R6.2 假設不同，說明，不另造多條候選線。

### P2 基礎移動與拔納刀

- 收刀／持刀待機、走／跑／疾跑／方向移動、起停、90°／180°轉身、跳落地。

## 12. 驗證：少而有用，不再堆一整個證據工程

### 12.1 每個代表性測試都需要三層結果

1. **資源層**：正確骨架／路徑／時長／非空軌道／事件；確認匯出真的寫到目標資源。
2. **引擎層**：實際輸入能觸發、骨頭與刀真的動、程式位移與碰撞正常、事件數正確。
3. **畫面層**：刀路、腳底、握位、輪廓與節奏看得清楚，交使用者審。

靜態檔案掃描不能代替後兩層；動畫名稱出現在選單也不代表有播放。

### 12.2 最少必測情境

| 類別 | 測什麼 | 通過條件 |
|---|---|---|
| 接地／步態 | 走、跑、疾跑、持刀側移，各完整左右腳週期 | 步速相符；接地誤差與滑移有數據 |
| 拔納刀 | 靜止／移動／快速斬尾段取消 | 無雙刀、無跳位、無時間倒退 |
| 連段 | 一下、兩下、三下、太早按、窗內按、過期按 | 只播放合法刀數，輸入不鬼畜積存 |
| 判定 | 揮空、命中、同一敵人多碰撞體、兩個敵人 | 每刀每目標結算一次，多刀按 hit group 正確結算 |
| 攻擊取消 | 切削前／中／後按移動、閃避、格擋 | 與既有規則及提案契約一致，不遺留傷害 |
| 防禦 | 窗內彈刀、窗外格擋、連續受擊、不可擋攻擊 | 結果與畫面一致，邏輯窗不憑動畫名稱推測 |
| 蓄力 | 未滿放、滿不放、滿放、0 位移、無目標、牆前 | 狀態可退出，不穿牆、不除零 |
| 空中型 | 地面起手、空中起手、斜坡落地、低頂、懸崖 | 起落由真實碰撞決定，不提前吸地 |
| 受擊／死亡 | 主斬中受擊、納刀中死亡、處決目標消失 | 清理舊 action；死人不繼續傷害 |
| 十三型 | 完整一圈、第二圈、中途受阻、缺件 | 語意順序正確，事件不漏／不重，缺件不冒充完整 |
| 調整滑桿 | 0／預設／最大、啟用／停用 | 全行程有效；0 的語意明確且真的生效 |

### 12.3 畫面交付預算

- 每輪預設局部檢查＋**最多一張審圖總表與四張單圖**；重用既有 capture 工具，不每輪新寫截圖腳本。
- 總表選預備／刀接近命中／主斬／隨揮／殘心／出口，至少保留一個玩家視角與一個側視。
- 快速斬不靠 0.1 s 間隔的六張圖宣稱所有幀正常；必要時保留短 MP4 或在斬擊窗口密取樣，再只輸出一張總表。
- 診斷時可暫隱袖子／火焰，但標示「診斷視圖」；正式美術畫面仍要恢復。
- 不建立 seal／reopen／reseal、不另建一次性 gate。不為這份動作規格擴張成全村／全專案回歸。
- 若真的修改 3D 世界擺放／地形／建物，另外遵守專案 placement validation；本文件本身沒有變更世界。
