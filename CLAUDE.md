# CLAUDE.md — Repository Constitution

Permanent operating rules for Claude Code in this repository. This file is
policy only. It holds no subsystem specifications and no project history.

Project: 幻想鄉 / 博麗神社 — a walkable 3D fan project. The live line is the
**Godot 4.4** build under `godot/`; `src/` is the frozen three.js line.
Geometry is generated by headless scripts (Blender → GLB → Godot), never
hand-modelled.

---

## Task Loading Protocol

At the start of every task, in this order:

1. Read `CLAUDE.md` (this file).
2. Read `docs/PROJECT_STATE.md`.
3. Read only the `.claude/rules/` files that apply to the task.
4. Read the one authoritative spec explicitly relevant to the task (see map).
5. Inspect `git status` / `git diff` / relevant commits.
6. Expand context further **only when concrete evidence requires it** — a
   failing check, a contradiction, a file the task must edit.

Do **not** automatically read all of `docs/`. Do not re-audit the repository.

---

## Permanent Rules

**Baseline**
- Human-approved baseline is locked.
- Do not reopen approved decisions without regression evidence.
- Preserve validated production pipelines.

**Scope**
- Work only within the requested Phase / subphase.
- No opportunistic refactors.
- No repo-wide audit by default.
- Stop when the current task is complete. Do not start the next phase.

**Reading**
- Prefer targeted reads over full-file reads.
- Prefer `git status` / `git diff` / relevant commits before reading files.

**Visual work**
- Visual changes require: prototype or slice → render → **Human Art Review**
  → rollout. All four, in that order.
- Never mass-deploy unapproved visual work.
- Token efficiency must never reduce required validation. Cutting a render,
  a gate, or a screenshot to save context is not allowed.

**Documentation**
- Maintain canonical project-state documentation when material state changes.

## Documentation Maintenance Protocol

On task completion:

| If | Then |
|---|---|
| Current project state materially changed | update `docs/PROJECT_STATE.md` |
| Roadmap status changed | update `docs/ROADMAP.md` |
| A permanent subsystem spec changed | update that subsystem's document |
| Nothing materially changed | **do not** rewrite docs to generate activity |

Human Art Review decisions are recorded **only after** human approval.

## Single Source of Truth

One fact lives in exactly one place. Never duplicate across documents.

| Information | Canonical location |
|---|---|

| Roadmap | `docs/ROADMAP.md` |

`docs/README.md` is the index. `docs/archive/` is history — do not read it
unless a decision is disputed.

## Reporting

A final task report normally contains only:

**Changed** · **Validation** · **Art Review** · **Known Risks** · **Status**

No implementation diaries. No re-explaining project history. No re-listing
decisions that were already settled.

## Non-negotiables

- Commit and push every round to the assigned branch.
- Never open a pull request unless explicitly asked.
- Never write the model identifier into commits, PRs, code, or docs.
