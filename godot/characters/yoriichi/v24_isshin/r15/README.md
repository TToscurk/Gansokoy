## 操作（試玩場景）

| 鍵 | 功能 |
|---|---|
| Z／X | 上一招／下一招（HUD 顯示招式名、狀態、來源、時間軸；沒有 JSON 的招式顯示「未完成」且 L 不出招） |
| L／滑鼠右鍵 | 出招（蓄勢期間 Space＝閃避取消） |
| Shift+L | 選到「圓舞（R15 新）」時直接出「圓舞一閃」 |
| T | 切換木樁位置（每招兩個：設計距離／近距離） |
| R | 重設位置 |
| V | 特效開／關 |
| B | 火車火焰：統一火環 ↔ Blender KS12（R12 預設） |
| WASD／滑鼠 | 移動與自由鏡頭（技能不會強制切鏡頭） |

## 已知問題（未修，留給驗收判斷）

- 斜陽轉身：橫斬末段左前臂扭轉較快（約 50–59°／格，連 4 格）；倒立橫斬時刀身離軀幹最近約 4 cm（可能擦到衣服）。
- 輝輝恩光：雙手只在下撲後半到主斬（梟在頂點把刀伸出去，左手伸直仍差 0.2 m，不硬拉）；落地縱劈的接觸點偏低（木樁約 0.7 m 高處）。
- 日暈之龍：瞬步是貼地滑行（艾瑪原動作也是）；收尾縱劈後一心的手腕有一個原動作自帶的快速翻腕。
- 灼骨炎陽：起跳時髖部一格約 54°（原動作的起跳甩身）。
- 所有「部分」都可以玩、有實際刀身判定；沒有用 Blender（改造都在離線 FK／IK `notes/r15/sunlib.py` 完成）。
