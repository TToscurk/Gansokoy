# R10：居合系統＋日之呼吸技能系統＋隻狼刀法庫（候選 ART_REVIEW）

試玩場景：`r10/r10_combat_demo.tscn`。正式 Player、跑酷、正式場景、共用骨架都沒動。R9／R9-C3 場景與資料原樣保留，原始程式刀光（`r9/sun_vfx.gd`）也保留，按 C 可切回。

## 操作
| 鍵 | 功能 |
|---|---|
| WASD | 移動 |
| Shift＋W | 跑；按住 0.45 s 以上轉衝刺 |
| Space | 閃避 |
| F | 跳躍（刀在手時） |
| G | 拔刀／納刀 |
| J／左鍵 | 攻擊。刀在手＝普通劍術派生；居合構＝目前選定的居合招 |
| 1–0、Tab | 選起手招。選到居合系的招（二連斬、居合上撩）＝設成居合構的攻擊，不會因此切換架勢或自動出招 |
| L／右鍵 | 日之呼吸；刀在鞘中會先拔刀再出 |
| Z／X | 切換日之呼吸的型 |
| M | 開關刀法庫；開啟時 J＝出刀法庫目前的招 |
| [ ] | 刀法庫上一招／下一招 |
| , . | 刀法庫換角色 |
| C | 特效版本：r9 → A → B → C1–C3 → L1 → L2 → R10；碧羅天、烈日紅鏡沒有的版本用 R10 |
| V | 特效開關 |
| N | 白天／黃昏森林 |

## 居合
- 居合斬 a100_003021（moveset key `iai`）已從預設攻擊路由移除：`r10/r10_moveset.json` 設 `enabled=false`。動畫與設定都保留，改回 `true` 即可恢復。
- 刀在鞘中可以走、後退、橫移、跑、衝刺、轉身、閃避。動作來自 c1400 居合型的 a100 移動組，烘製時右手扶柄、左手握鞘口（`notes/r10/build_sheathed_loco.py`）；停下後回到居合構。
  - 共用控制器 `combat_locomotion.gd` 新增選用欄位 `sheathed`，場景沒設就是舊行為。
  - `isshin_dojo_demo.gd` 新增 `auto_draw_on_move`、`auto_pending_after_switch`，預設值仍是舊行為；R10 把兩者都關掉。
- 武器邏輯狀態顯示在 HUD：刀在鞘中、居合構、拔刀過渡、刀已出鞘、普通劍術攻擊中、居合攻擊中、納刀過渡、日之呼吸。
- 居合招在納刀前被取消，刀留在手上；不取消就完整納刀，回到居合構。
