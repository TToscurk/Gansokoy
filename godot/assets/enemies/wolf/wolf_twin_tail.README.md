# wolf_twin_tail.glb — 雙尾狼

Tripo 生成 + 手工補骨與動畫。匯出後以 headless Blender 重新匯入驗證通過。

- 網格 45,920 頂點 / 1 material
- 貼圖 4096×4096 ×3：Color、Normal、Metallic-Roughness
- 骨架 58 根，24 fps
- 原始檔：`D:\神社\shrine\work\wolf_rig\wolf_v3.blend`

## 動畫

| Action | 幀 | 秒 | 循環 | 說明 |
|---|---|---|---|---|
| `Idle` | 0–120 | 5.00 | ✔ | 呼吸 1.2s/次、頭部巡視 ±8.7cm、耳朵抽動、雙尾反相擺動 |
| `Walk` | 0–24 | 1.00 | ✔ | 四拍 HL→FL→HR→FR，步幅 26cm、抬 6.5cm，含趾骨滾動 |
| `Run` | 0–16 | 0.67 | ✔ | 奧步 rotary gallop，步幅 34cm，騰空 3 幀，脊椎屈伸 ±4° |
| `Charge` | 0–88 | 3.67 | ✘ | 前搖蓄力（刨地）→ 奔馳 → 肩撞 → 收勢 |
| `Slam` | 0–90 | 3.75 | ✘ | 蓄力 → 跳高 62cm → 滯空 → 砸地壓縮 22cm → 回彈 |
| `Gatsuga` | 0–96 | 4.00 | ✘ | 牙通牙式自轉衝鑽，需搭配特效 |
| `Dissolve` | 0–96 | 4.00 | ✘ | 死亡：不倒下，仰頭上浮 40cm 後化為光點 |

全部動畫穿地量 = 0（逐幀量測網格最低點，以 Root 補償）。

## 攻擊鏈接法

```
Idle → Walk / Run → Charge（衝撞）
                  → Slam（範圍震地）
                  → Gatsuga（突進，需特效）
死亡 → Dissolve
```

## 特效參數

### `gatsuga_fx.json`

旋轉段 f30–73（44 幀 / 1.83s），繞體心 z=0.395 自轉 3 圈。

| 參數 | 值 |
|---|---|
| 角速度 | 589°/s（1.64 轉/秒） |
| 旋轉體半徑 | p90 平均 0.274 m，最大 0.463 m |
| 前進距離 | 0.453 m |
| 體心高度 | 0.400 → 0.720 → 0.400（拋物線） |

逐幀欄位：`cx/cy/cz`（體心）、`r90`/`rmax`（半徑）、`active`（是否在旋轉段）。

**本體動畫是「側翻」而非真正捲成鑽頭**——這隻脊椎只有 2 節，弓不成球。
必須配旋風／殘影／速度線材質遮蔽，否則看得出四肢還伸在外面。
用上表半徑做圓柱狀特效即可覆蓋。

### `dissolve_fx.json`

| 欄位 | 用途 |
|---|---|
| `dissolve` 0→1 | shader 溶解門檻。f20 起、f88 完全消失，smoothstep 曲線 |
| `emit_rate` | 光點粒子發射量。f40–60 最強（0.88–0.97），頭尾收斂到 0 |
| `zmin`/`zmax` | 該幀身體上下界，做 bottom-up 掃描遮罩 |
| `cx`/`cy`/`cz` | 體心，粒子發射器跟隨 |

建議：noise 貼圖 + `dissolve` 門檻，由下往上掃（腳先化、頭最後），邊緣加發光帶；
粒子在 `zmin`~`zmax` 之間依 `emit_rate` 生成往上飄。

## 注意事項

- **原地動畫**，無 root motion。位移全部由程式驅動。
- 匯出時有頂點受 4 根以上骨影響，glTF 取權重最高 4 根並歸一化（標準行為）。
- 尾巴與後腿在網格上有輕微黏連（Tripo 生成瑕疵，左 77 邊 / 右 51 邊）。
  已用權重調整緩解，走路等小幅動作看不出來；大幅擺尾仍可能有輕微牽動。
- 嘴部無口腔幾何，`bone_9` 只能小幅開合，做不出真正張嘴咬合。
